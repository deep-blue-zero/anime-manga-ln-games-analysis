# Interactive

[atlas.html](atlas.html) is the unchanged, self-contained Interactive Ethical Atlas v3. Download it and open the downloaded HTML file directly in a modern browser. No network fetch or local server is required; viewing its source on GitHub does not execute it.

It retains the ethics map, supplied PCA projection, Ward k=8/10/12 color views, seven-axis Euclidean nearest neighbors, up to four selected-subject radar profiles, labels/search, unit filter, and circle/diamond/triangle markers for characters, factions, and historical agents.

The [CSV](../data/pactrih_scores.csv) is the numerical authority. This atlas is a frozen verified projection, not an independently editable score source. Its supplied PCA coordinates, cluster IDs/color mapping, and priority flags are byte-pinned because an exact producer rebuild is unavailable. Follow the [update procedure](../scripts/README.md). PACTRIH-SR and public hosting are outside this import.
