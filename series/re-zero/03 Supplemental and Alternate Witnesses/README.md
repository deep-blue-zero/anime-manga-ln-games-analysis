# Re:Zero — supplemental and alternate witnesses

This directory owns analytical readings of admitted material that is **not part of the governing numbered main-light-novel spine**.

No supplemental reading is present through V03.

Bibliographic awareness is maintained separately in `../01 Source Lock and Inventory/REZERO_SUPPLEMENTAL_WITNESS_CATALOG.md`. A catalog row or family-awareness row is not a source admission and does not authorize narrative opening.

## Admission before interpretation

Every item must first have sufficiently exact identity in the supplemental catalog and then exist in `../01 Source Lock and Inventory/REZERO_SOURCE_LOCK_AND_INVENTORY.md` as an acquired, integrity-audited witness with a source class and analytical horizon. `H_pub`, `H_diegetic`, `H_route` where applicable, and conservative `H_final` must be recoverable before opening.

Do not read an acquired item merely because it is interesting or apparently short. Publication timing and route placement can create retrospective spoilers that corrupt the prospective main-volume chain.

The V03-paratext preview of a separately published serial story remains an unresolved catalog lead, not an admitted witness. It stays unopened while the post-V03 pause is active and until exact identity and horizon routing are established.

## Witness-specific responsibilities

### Mainline supplemental material

Use for source-verified side stories, supplemental/EX material, short-story collections, or comparable witnesses that belong to the main continuity but sit outside the numbered spine.

Record:

- exact source identity;
- publication and diegetic placement;
- focalizer;
- what main-volume freeze it is allowed to revise;
- whether it confirms, extends, complicates, or revises the current model.

### Alternate-route / IF material

Keep route identity explicit in the filename and front matter. Analyze it as a counterfactual witness.

Do not merge route-specific history into main-route chronology or character responsibility.

### Web-novel material

Use only as a version/developmental witness unless a future project explicitly changes the governing source hierarchy.

Version comparison should name both loci being compared and distinguish changed wording, scene structure, characterization, mechanics, and exposition.

### Other admitted material

Reference books, interviews, games, promotional text, or other sources require a declared analytical role before they receive a file here.

## Suggested filename pattern

Use a stable source ID from the inventory, for example:

`REZERO_SUPPLEMENT_<SOURCE_ID>_READING.md`

For alternate routes, include the route/source identity when that improves retrieval, but do not invent a fandom-derived canonical label when the admitted source provides a better one.

## Cross-witness rule

Every reading should state whether its findings are:

- local to the witness;
- admissible into the main-route model within a verified scope;
- useful only for counterfactual comparison;
- useful only for version/adaptation comparison;
- unresolved pending more evidence.
