**Identity row unit:** one native speaker/role/variant/contact occurrence or demonstrably shared key. Fields: record ID; source lock, artifact and exact field; native key/display label; candidate analytical subject(s); identity type `RESOLVED/AMBIGUOUS/COMPOUND/GENERIC/HIDDEN/UNBOUND`; frame/role/form; correspondence evidence; negative/exclusion evidence; language; conditions; scope of decision; reviewer; prior decision; successor. Never globally replace a generic display label or propagate a source-local key to another build without proof.

**Join row unit:** one relation between source objects. Fields: source/target keys and namespaces, join rule and normalization version, candidate cardinality zero/one/many, native link evidence, reachability/condition, missing or conflicting pointers, chosen result or `UNRESOLVED`, and affected evidence/claims. A near-match is not a successful join. Corrections preserve old result and dependent retest obligations.

**Dedup row unit:** one native evidence identity across views/branches. Fields: canonical native identity, source fingerprint, all projection/packet occurrences, common-prefix/shared-script status, semantic differences if any and counting unit. Multiple target bundles containing the same line count once. Genuinely independent branch occurrences remain independent only when established from native structure.

Update when actual source inspection establishes a binding, contradiction or changed build. Append adjudication history and preserve old-state validity. Reading must stop on a load-bearing unresolved identity rather than manufacture a speaker. State and claim records link these IDs and may not silently override them.
