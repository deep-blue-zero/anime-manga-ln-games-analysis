# 4. Bundle-internal routing

For each anime source unit, prefer:

1. bundle metadata / manifest;
2. dialogue index;
3. corrected Japanese subtitle object;
4. complete audio;
5. contact sheet for reconnaissance;
6. full-resolution frame for visual claim;
7. continuous-video escalation for temporal claims.

When a deep reading cites a frame, preserve:

- exact bundle filename;
- frame filename;
- timestamp;
- source scope.

When it cites dialogue, preserve:

- Japanese text;
- subtitle cue/timestamp;
- audio interval when performance matters.
