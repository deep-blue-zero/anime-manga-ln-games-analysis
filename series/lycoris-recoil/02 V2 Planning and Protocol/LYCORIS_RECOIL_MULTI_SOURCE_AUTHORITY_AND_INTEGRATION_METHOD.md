# Lycoris Recoil Multi-Source Authority and Integration Method

## 1. Purpose

This document governs how *Lycoris Recoil* V2 admits, reads, compares, and integrates evidence from sources outside the originating anime corpus.

Its central purpose is to prevent a common failure mode in multi-source character analysis:

> **a behavior becomes "what the character is like" merely because it appeared in an official derivative work.**

The method therefore separates four operations that must not be collapsed:

1. **source authentication and authority classification**;
2. **source-native interpretation** of the work as an authored artifact in its own medium;
3. **source-local characterization extraction**;
4. **promotion, non-promotion, or pressure against the integrated model**.

A source may be analytically excellent without having authority to rewrite the anime-native model.

---

# 2. Governing principle

> **Every source is first allowed to be itself. Character evidence enters the integrated model only after its provenance, genre pressure, creator proximity, continuity role, and compatibility with stronger evidence remain visible.**

Two statements must always remain distinguishable:

- **Source-local fact:** “Chisato does X in *Recollect* chapter Y.”
- **Integrated character claim:** “Chisato generally tends to do X under condition Z.”

The first may be directly factual within that source. The second requires explicit promotion.

---

# 3. Source classes

The V2 architecture defines the following default source classes.

## `A1_ORIGINATING_AUDIOVISUAL`

TV E01-E13 and *Friends are thieves of time* Shorts 01-06.

Primary authority for:

- depicted anime events;
- Japanese performed characterization;
- visual embodiment;
- action;
- timing;
- anime-native relationship state;
- anime-native behavioral base rates.

The frozen A1 reconstruction remains permanently recoverable even after integrated models are later expanded.

## `A2_CREATOR_PROXIMATE_SUPPLEMENTARY`

Currently expected to include the Asaura prose volumes admitted by the source inventory.

High value for:

- unrepresented everyday states;
- interiority;
- prose-specific characterization;
- new relationship situations;
- expansion of behavioral coverage.

A2 evidence may legitimately pressure or revise an integrated model more strongly than derivative sources, but it still cannot be silently written backward into the frozen A1 baseline.

## `B1_OFFICIAL_SINGLE_AUTHOR_DERIVATIVE`

Currently expected to include *Recollect*.

High value for:

- source-local characterization;
- everyday/comedic state coverage;
- cross-author convergence;
- permitted characterization range.

B1 cannot by itself revise a high-confidence A1 rule.

## `B2_OFFICIAL_ADAPTATION`

Direct adaptation of already available narrative material, such as the main manga if later admitted.

Useful primarily for:

- selection/omission;
- alternate emphasis;
- added connective beats;
- adaptation-specific characterization.

## `C1_MULTI_AUTHOR_LICENSED_INTERPRETATION`

Official anthologies and comparable multi-author material.

Useful for:

- contributor-level characterization;
- franchise invariants;
- salience across independent creators;
- deformation envelopes;
- gag amplification.

C1 is weak evidence for behavioral base rates unless stronger sources converge.

## `P_PARATEXT`

Interviews, production commentary, official descriptions, publication notes, and creator statements.

Paratext is contextual evidence. It does not replace dramatic evidence.

# 4. Authority is multidimensional

Do not reduce authority to a single ladder.

For every admitted source, record where relevant:

| Dimension | Question |
|---|---|
| Continuity authority | Does the source establish events in the same dramatic continuity, an adjacent continuity, or only its own licensed scenario? |
| Characterization authority | How strongly should its behavior constrain an integrated model? |
| Creator proximity | Is it authored by originating story staff, supervised by them, adapted by an outside creator, or multi-author licensed material? |
| Supervision evidence | Is close supervision explicitly documented, merely possible, or unknown? |
| Medium independence | Is this new material or a re-rendering of existing material? |
| Genre pressure | Does gag comedy, parody, romance, action, or another form structurally amplify traits? |
| Temporal placement | Where does the source plausibly sit relative to anime character/relationship development? |
| Evidentiary uniqueness | Does this source test a state absent from stronger sources? |

Authority uncertainty must be preserved as uncertainty.

Do not infer:

- `Spider Lily 原作` = line-by-line creator supervision;
- official publication = identical characterization authority;
- originating creator authorship = automatic consistency with every prior depiction.

---

# 5. Source admission gate

A supplementary source is not analytically integrated merely because a file exists in Drive.

Before reading for V2 integration, confirm:

1. exact source identity;
2. Japanese-language status;
3. edition/publication identity where recoverable;
4. creator/contributor metadata;
5. source class;
6. continuity/supervision status or explicit uncertainty;
7. file integrity;
8. whether the source is mandatory, optional, or excluded by the current V2 boundary.

The canonical source inventory governs the currently admitted set.

If a later source is added, update the source inventory before analytical integration.

# 6. Source-native reading quarantine

## 6.1 First-read rule

The first analytical pass through a new supplementary source asks:

> **What is this work doing as a work?**

not:

> **Which existing Chisato policy can I confirm?**

During source-native reading:

- existing character models may guide questions but not force interpretations;
- source-local divergences are recorded rather than normalized;
- genre/form is analyzed before deciding whether a behavior generalizes;
- character evidence is extracted only after the source-native reading has established scene/story function.

## 6.2 Why this quarantine exists

Without it, the project risks two opposite confirmation errors:

1. forcing every new source to agree with the anime-native model;
2. allowing the newest source to overwrite the model simply because it is vivid and recent.

Source-native reading creates a recoverable intermediate layer between source and integration.

---

# 7. Prose-specific authority handling

For the Asaura novels, distinguish:

- direct quoted/spoken dialogue;
- direct thought;
- focalized narration / free indirect discourse;
- narrator assertion;
- external action;
- analyst inference.

A prose sentence may be more explicit than the anime without necessarily proving that an earlier audiovisual inference was correct.

When prose appears to confirm an anime interpretation, ask:

1. Did the anime independently support this before the prose was read?
2. Is the prose presenting stable cognition, a momentary rationalization, or narrator framing?
3. Does the new evidence strengthen a base rate, extend a state space, or merely demonstrate possibility?

The anime-native baseline must remain unchanged as a historical object even when the integrated model later strengthens.

---

# 8. Recollect-specific handling

*Recollect* should be treated as a single-author official derivative realization.

For each chapter or cluster, preserve:

- Abe Kanari’s local characterization;
- gag/comedy structure;
- repeated behavioral tendencies;
- reaction magnitude;
- physical-comedy grammar;
- relationship assumptions;
- temporal placement uncertainty;
- compatibility/divergence from A1.

A recurring behavior across *Recollect* establishes a **Recollect-local base rate** before it establishes an integrated base rate.

Do not reason:

> Abe writes Takina literally three times → anime Takina is more literal than previously thought.

Instead reason:

> Abe repeatedly uses literalism as a Takina comedy engine → strong Recollect-local pattern; compare with A1/A2 frequency and context before integration.

---

# 9. Anthology contributor firewall

The basic unit of anthology evidence is:

> **contributor + story + character realization**

not:

> **the anthology**.

Track independently:

- writer/artist;
- story title;
- tone/genre;
- character cast;
- salient behavioral choices;
- compatible extensions;
- exaggerations;
- contradictions;
- recurrence across contributors.

## 9.1 Independent convergence

If multiple unrelated contributors independently reproduce the same trait, this can strengthen the claim that the trait is a **high-salience franchise characterization attractor**.

It does **not** automatically establish that the trait is frequent in the originating anime.

Example distinction:

- “Takina literalism is highly salient to licensed creators” — supported by repeated anthology convergence.
- “Takina responds literally in most ambiguous social situations” — requires stronger base-rate evidence.

# 10. Genre-pressure tags

Every supplementary story should receive a genre-pressure description when relevant.

Suggested tags include:

- `EVERYDAY_PROSE`
- `DRAMATIC_PROSE`
- `GAG_COMEDY`
- `YONKOMA`
- `ROMANTIC_COMEDY`
- `ACTION`
- `SENTIMENTAL_SLICE_OF_LIFE`
- `PARODY`
- `MIXED`

Genre pressure is not a discount applied mechanically. It is a reminder to ask what the form incentivizes.

Common comedy pressures include:

- greater reaction amplitude;
- compressed setup/payoff;
- trait repetition;
- misunderstanding;
- faster conflict reset;
- exaggerated embarrassment;
- simplified straight-man/fool role assignment.

# 11. Integration classifications

After source-native reading and source-local extraction, compare each proposed generalization against the current integrated model.

## `CONFIRM`

The new source independently reproduces an already established rule without materially changing its scope.

Effect:

- increase cross-source support;
- do not automatically broaden conditions or frequency.

## `EXTEND`

The source tests a state or relationship condition absent or weakly represented in stronger sources, and the behavior remains structurally compatible.

Effect:

- add a supplementary extension with provenance visible.

## `SPECIFY`

The source reveals a conditional modifier that sharpens a broad rule.

Effect:

- refine the integrated rule if authority and evidence justify it.

## `PRESSURE`

The behavior is sufficiently surprising that the current model should be reviewed, but evidence does not yet justify revision.

Effect:

- open a pressure item;
- seek stronger or convergent evidence.

## `CONTRADICT`

The source conflicts with a high-confidence rule under apparently comparable conditions.

Effect:

- preserve the conflict;
- do not invent an unobserved harmonizing condition.

## `CARICATURE`

The source appears to amplify a real trait in frequency or magnitude for genre purposes.

Effect:

- retain as characterization-envelope evidence;
- normally do not change baseline frequency.

## `SOURCE_SPECIFIC`

The behavior is meaningful for that author/medium realization but lacks sufficient basis for general promotion.

## `OPEN`

Insufficient evidence to decide.

# 12. Base-rate firewall

This is a hard methodological rule.

> **Capability evidence and frequency evidence are different.**

A source can establish:

> Chisato is capable of behavior X.

without establishing:

> Chisato usually chooses behavior X.

Derivative/gag sources may expand the **possible characterization envelope** far more easily than they alter the **probability distribution of ordinary behavior**.

When integrating, explicitly ask:

- Does this source show possibility?
- Does it show recurrence within that source?
- Does it show recurrence across independent sources?
- Does stronger A1/A2 evidence support similar frequency?

---

# 13. Asymmetric revision threshold

No B1, B2, or C1 source may by itself `REVISE`, `DOWNGRADE`, or `REJECT` a high-confidence A1 behavioral rule.

It may:

- `PRESSURE`;
- `CONTRADICT` locally;
- establish a source-specific alternative;
- reveal a new possible state;
- contribute to later revision when A2 or additional strong evidence converges.

A2 evidence receives greater revisionary weight because of creator proximity, but even A2 does not rewrite the frozen A1 baseline. It may revise only the **integrated** model through an explicit finding.

---

# 14. Cross-source convergence

Promotion strength increases when independent evidence converges across dimensions such as:

- A1 repeated behavior;
- A2 independent depiction;
- B1 compatible extension;
- multiple C1 contributors;
- different relationship contexts;
- different stakes;
- different genres.

Do not count repetitions inside one derivative source as if they were independent authorship evidence.

A useful qualitative convergence vocabulary is:

- `SINGLE_SOURCE`
- `WITHIN_SOURCE_RECURRENT`
- `CROSS_SOURCE_COMPATIBLE`
- `CROSS_SOURCE_RECURRENT`
- `CROSS_AUTHORITY_CONVERGENT`
- `INVARIANT_CANDIDATE`

These labels describe support topology, not certainty by themselves.

---

# 15. Source-local models

For important characters, preserve separately when useful:

- `ANIME_NATIVE`
- `ASAURA_PROSE`
- `RECOLLECT_ABE`
- `ANTHOLOGY_CONTRIBUTOR_<X>`
- `ANTHOLOGY_AGGREGATE_SALIENCE`

This makes it possible to ask:

- what survives every realization;
- what only Asaura externalizes;
- what Abe exaggerates;
- what anthology creators repeatedly seize upon;
- where a derivative source departs from the originating distribution.

The integrated model must not erase those source-local differences.

---

# 16. Contradiction handling

When sources conflict:

1. verify that the conditions are actually comparable;
2. verify chronology/relationship state;
3. verify translation/medium evidence;
4. verify genre pressure;
5. verify source authority;
6. preserve the conflict if no evidenced modifier resolves it.

Allowed unresolved result:

`OPEN_CROSS_SOURCE_CONTRADICTION`

Do not invent:

> “She behaves A only when X but B when Y”

unless X/Y is supported by evidence.

---

# 17. Prospective supplementary validation

Where a chapter/story premise can be known without reading its actual behavioral resolution:

1. record premise only;
2. use the current frozen model to predict behavior classes;
3. freeze the prediction;
4. read source-native;
5. compare prediction to source behavior;
6. classify difference.

A prediction failure can mean:

- integrated model incomplete;
- state/relationship modifier missing;
- genuine creator-proximate extension;
- derivative drift;
- genre caricature;
- premise under-specified.

Do not score prediction failure automatically as model error.

# 19. Character Evidence Matrix

The evidence matrix should eventually support rows such as:

| Policy | Anime | Shorts | Ordinary | Recovery | Gluttony | Recollect | Anthologies | Integrated authority |
|---|---|---|---|---|---|---|---|---|

Cells should contain observation IDs or concise support states, not generic checkmarks.

This matrix exists to reveal:

- overdependence on one medium;
- untested state-space regions;
- apparently invariant behavior;
- derivative-only behaviors;
- contradiction clusters.

---

# 20. Promotion to mature reconstruction

A supplementary observation may enter the default integrated reconstruction only when its status is explicit.

The mature character model should preserve four layers:

1. **Core invariant model** — strongly grounded in A1 and stable across strong evidence.
2. **Supplementary extension model** — high-confidence additions from strong supplementary evidence.
3. **Characterization envelope** — plausible but lower-authority licensed behaviors.
4. **Source-local variants** — realization-specific behavior excluded from default simulation.

Default simulation uses:

> **Core invariant + supplementary extension**

unless a different mode is requested.

---

# 21. Completion gate for each supplementary source

A supplementary source is not integration-complete until:

- source-native reading exists;
- authority/genre metadata is recorded;
- character observations are extracted;
- source-local patterns are identified;
- proposed cross-source promotions are classified;
- contradictions remain visible;
- claim revision is routed where necessary;
- character evidence matrix is updated when initialized;
- current-state map is updated if source boundary or authority materially changes.

---

# 22. Failure modes

Do not:

- use “official” as a substitute for authority analysis;
- convert one derivative gag into a stable trait;
- count repeated behavior from one author as independent convergence;
- use anthology consensus as direct anime frequency evidence;
- treat creator-proximate prose as if it were audiovisual performance evidence;
- rewrite the frozen anime-native baseline;
- erase contradictions through invented conditions;
- assume absent supervision because public evidence is absent;
- assume close supervision because an IP credit exists;
- merge source-local and integrated character models invisibly.

---

# 23. Governing rule

> **Supplementary material may freely deepen our understanding of its own realization. It enters the integrated model only by explicit, provenance-preserving promotion, and lower-authority material may pressure but cannot silently overwrite stronger anime-native evidence.**
