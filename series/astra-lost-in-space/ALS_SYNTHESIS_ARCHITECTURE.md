# Omnibus synthesis architecture

## 1. Scope and authority

ALS-G1 occupies `series/astra-lost-in-space/` with one [current entrypoint](CURRENT_STATE_AND_CORPUS_MAP.md), paired [method](ALS_ANALYTICAL_METHOD.md) and no prior architecture superseded. The available source is one Japanese 全巻合本版 EPUB. Metadata calls it complete; actual internal unit identity and completeness are not verified.

The design separates container identity from analytical sequence. The intended corpus preserves natural unit readings, knowledge/development states, directed relationships, Japanese expression and page form, then converges into a source-bounded series interpretation. One large file is neither one adequate deep reading nor permission to consume the whole source at once.

Canonical status governs INITIAL procedure only. No narrative source, character or plot finding exists, and no owner run is authorized. Source mapping can proceed within bounded bootstrap/reconnaissance scope; narrative admission needs the separate gate.

## 2. Source model and homes

The source/unit map preserves one immutable witness alias and will map actual internal volume/chapter labels to global image occurrences. Prefer visibly defined volume units; if absent, use actual chapters with a documented decision before authorization. No invented volume count or synthetic source files.

Narrative, internal title/contents pages, notes, profiles, extras and previews need component/spoiler classification. Other editions, translations and adaptations are excluded. A later same-file unit is outside an earlier prospective horizon even though transport delivered it together.

Day-one homes: source/unit map; method; architecture; state/evidence ledger; claim revision ledger; current entrypoint; producer review; local descriptor. Future `readings/` contains each mapped unit's full argument, `checkpoints/` contains actual frozen tranche states, and `studies/`, `reconstruction/`, `audits/` appear only when substantive outputs earn them.

The state/evidence ledger preserves person/knowledge/directed/contextual samples through typed records sharing a verified unit key. The claim ledger preserves interpretation and revisions. Neither substitutes for full causal prose.

## 5. Studies and analytical depth

Major character work must explain transitions, motive/self-report, behavior, ordinary versus crisis evidence, relationship conditioning, language/form, counterexamples and uncertainty. A relationship argument must preserve both directed perspectives and their causal effects. A character earns an independent monograph when a distinct developmental question across admitted units requires sustained treatment; a bounded one-unit case may instead warrant a scoped study.

Required mature responsibilities are character/causality, knowledge/chronology, directed relations, Japanese expression and page form. They may be substantial integrated sections where independent specialists add no retrieval or argument value. The role-gap audit must name those sections and explain why no separate specialist is needed. A collective-system or other domain specialist is earned by actual recurring evidence, not by title familiarity.

A full-series synthesis integrates those arguments and their disagreements; it cannot concatenate unit summaries. No universal word ceiling applies. Acceptance requires causal mechanisms, inferential warrants, representative/disconfirming evidence, clear named agents, competing readings and meaningful limits. During transfer compare complete incoming/outgoing prose for lost reasoning. Table density or file length alone is no certificate.

## 6. Conflict handling and dependency gates

For contradiction, verify unit mapping/witness first, then source layer, attribution, event time, disclosure, frame and knowledge. Test changed context/state, mistaken belief, retrospective explanation, edition variance or genuine inconsistency. A later revelation may justify REVISE or REVEALED_NOT_NEW without rewriting an earlier freeze. Unresolved competing accounts stay OPEN; changed central premises reopen dependent arguments.

Production order:
`verified omnibus/unit map → owner-defined run and OPEN gate → natural-unit readings plus synchronized ledgers → tranche checkpoint → actual source completion audit → longitudinal/claim reconciliation → role-gap/specialist readiness → substantive studies → convergence → integrated synthesis → validation → declared-scope freeze`.

| Gate | Condition |
|---|---|
| Bootstrap review | Meaningful source-specific pair/control schemas; CLOSED/no run |
| Unit-map readiness | Exact internal labels, order, spans and global coordinate map verified sufficiently to define run |
| Admission | Owner scope, bound witness and adequate inspection route, consistent OPEN fields |
| Unit completion | Full causal reading, coverage, counterreading, cumulative updates and exit freeze |
| Source-sequence completion | Every mapped authorized unit/accounted exclusion checked; omnibus “complete” label insufficient |
| Longitudinal reconciliation | State, knowledge, edges, expression and claims aligned to same horizon |
| Character/specialist readiness | Role-gap and locator/evidence stabilization; ordinary/contextual gaps stated |
| Specialist convergence | Conflicts resolved or bounded; integrated-section rationale if no separate specialists |
| Integrated-synthesis readiness | Required inputs complete and full arguments preserved for declared source scope |
| Final validation | Source/causal/counterreading/name-reference and exact repository checks |
| Release/freeze | Accepted scope and immutable records named through proper integration route |
| Model acceptance | Separately tested subject/state model; evaluator retains capability authority |

Reading completion or file closure does not automatically authorize retrospective synthesis, new sources or model generation.

## 7. Reconstruction as a separate derived pathway

Adapt the [generic reconstruction method](../../governance/analytical-methods/GENERIC_CHARACTER_RECONSTRUCTION_METHOD.md), especially §§9–12 and 14–18, as binding duties for any future model. This section supplies local scope; those duties are not waived by the compact file layout.

Prospective evidence capture records person/state, verified internal unit and global locator, witness/frame, situation/stakes, interlocutor, direct speech/behavior/interiority/report/observer/inference class, full reading/claim route, Japanese status and counterexample. Preserve ordinary-life opportunities, negative-evidence conditions and directed relationship contrast. Unknown contexts are gaps, not evidence-backed limits.

Create separate evidence map, operational model and validation record per subject/state when evidence earns them; monographs remain literary interpretation. Bind exact evidence-base commit, source/temporal/disclosure horizon, exclusions and version. Separate stable disposition, developmental state and transient conditions, with explicit change causes including REVEALED_NOT_NEW. A full-omnibus retrospective model cannot silently describe an early state.

Rules specify trigger + perceived stakes + current state → response family with inhibitors, overrides, exceptions, counterevidence, rivals and falsifiers. OBSERVED/CANDIDATE_POLICY/PROMOTED_POLICY reflect evidence and actual testing. Appraisal leads to decision/objective, speech act, relationship filter, Japanese register and wording; private thought is not public speech. Evaluate decision and surface fidelity separately.

Use HIGH/MODERATE/LOW/OPEN confidence and D0 attested/D1 near-variant/D2 new in-world-state/D3 cross-scenario distance. D3 specifies chronology, relationship and setting assumptions and abstains when evidence cannot constrain behavior. No acoustic/performance model is supported by manga alone.

Held-out evidence must be genuinely unexposed to the model author before fitting. The omnibus's later internal units may be held out only under a deliberate access boundary and owner-authorized later admission, not after remembered outcomes have entered the model. If already exposed, label RETROSPECTIVE_CONSISTENCY_TEST. Freeze predictions/rule IDs/state/assumptions/confidence/distance/falsifiers before releasing test material.

An independent reviewer adjudicates with exact evidence and diagnostic opportunity as SUPPORTED/PARTLY_SUPPORTED/CONTRADICTED/NO_DIAGNOSTIC_OPPORTUNITY/CONFOUNDED/UNRESOLVED. Use context/interlocutor perturbations, decoys, abstention controls, ordinary situations and generic-personality baseline where appropriate. Qualitative fidelity and counts/exclusions replace unsupported accuracy percentages.

Generated dialogue/scenes/predictions are synthetic outputs, never source observations or evidence of characterization. No simulation is authorized now. A model cannot fill unmapped or uninspected units. The project describes coverage across twelve evaluator dimensions/six scenario types; designated discovery/evaluation agents alone write their global records or grades.

## 8. Lifecycle and preservation

INITIAL. Review after first accepted natural unit, at a meaningful mapped tranche, on source-map revision, at sequence completion, before specialist/synthesis work and before release. No numeric checkpoint is invented before actual internal structure is known.

Role-gap findings use SATISFIED/PARTIALLY_SATISFIED/MISSING/MISROUTED/TOO_THIN/NOT_APPLICABLE, with exact home, evidence, consequence and repair owner. Add an independent ledger/specialist only for recurring evidence and retrieval needs inadequately served now. Backfill only material gaps.

Current indexes, entry, method and architecture are mutable by targeted changes with history. Source bindings/maps, evidence events, forecasts and prospective freezes remain append-preserving. Correct frozen readings by errata/revisions, not silent state rewrite. Changed unit boundaries preserve crosswalk/history and trigger locator review. Assessed model versions survive supersession. No fictional completed-run seal is created.

This bootstrap used metadata access, not a presumed manga-perception capability.
