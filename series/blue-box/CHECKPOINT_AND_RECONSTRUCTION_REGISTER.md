## Model and transfer rules

A model is distinct from a monograph and cannot silently pool manga and prose evidence. Conditional policies include triggers/stakes/state, response families, inhibitors, exceptions, counterevidence/rivals/falsifiers. Separate disposition/condition; trace appraisal → decision → recipient-conditioned expression. Record confidence, evidence distance and abstention/multiple-response criteria.

Freeze genuine held-out predictions before exposure. Independent evaluators use diagnostic baselines/controls with opportunities and confounds explicit. Exposed exercises are RETROSPECTIVE_CONSISTENCY_TEST; synthetic output is never primary or canonical evidence. Designated agents own global discovery/readiness registries.

Accept full independent readings and synchronized registers atomically. Verify actual channel coverage, exact retrieval, lane/knowledge boundaries, ordinary controls and full argument depth. Comparison requires prior accepted readings and explicit scope; a crosswalk is not a replacement source analysis.

A run defines actual cadence; architecture's four-volume main proposal is not authorization and does not apply mechanically to prose. Under the [handoff contract](../../governance/source-policies/MANGA_ANIME_ANALYTICAL_HANDOFF_AND_INTEGRATION_CONTRACT.md), transfer full files, compare base/candidate/current and inspect for lost causal, ordinary, linguistic, formal or counterreading detail.
