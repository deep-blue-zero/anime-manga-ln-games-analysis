# Solo Leveling — V2 novel–manhwa correspondence

Use this map to look up the prose sequence behind the collected English manhwa. The boundaries refer to the matched scene. A displayed chapter range can include reordered or omitted passages and can share a chapter with the adjacent volume. The [source verification](../02%20Source%20Audits/Solo_Leveling_V2_Source_Verification.md) identifies the editions and reproduces the locators. The [merged Phase 3 audit](../02%20Source%20Audits/Solo_Leveling_Phase_3_Korean_Source_Evidence_Audit.md) supplies the starting page coverage. New checks and retained qualifications attach to particular scenes.

The Phase 2 categories distinguish retained material (**Preserved**), shorter presentation (**Compressed**), a local absence (**Omitted**), greater emphasis (**Expanded**), changed function (**Transformed**), different placement (**Relocated**) and changed sequence of contributing scenes (**Recomposed**). **Manhwa-original** applies to the precise observed feature whose lack of a prose counterpart is supported. **Source-uncertain** marks a boundary or detail still requiring verification. A sequence can contain both inherited events and adaptation-specific staging.
