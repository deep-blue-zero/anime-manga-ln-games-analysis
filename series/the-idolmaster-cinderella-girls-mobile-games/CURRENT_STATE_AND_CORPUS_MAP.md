# CURRENT STATE AND CORPUS MAP — THE IDOLM@STER CINDERELLA GIRLS (Mobile Games)

## Purpose

This is the canonical analytical entrypoint for the **Cinderella Girls mobile-game corpus**, distinct from the completed/frozen analytical root for **THE IDOLM@STER CINDERELLA GIRLS (2015)** television anime.

The mobile-game project reconstructs selected idols from preserved original Japanese evidence drawn principally from:

- **THE IDOLM@STER CINDERELLA GIRLS** / Mobage social game;
- **THE IDOLM@STER CINDERELLA GIRLS STARLIGHT STAGE** / デレステ.

The extraction/corpus infrastructure and generated evidence packets are maintained separately from analytical synthesis. Character packets are evidence views; character monographs are interpretive analytical artifacts.
