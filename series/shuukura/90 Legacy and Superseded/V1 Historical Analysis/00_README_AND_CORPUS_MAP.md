# SHUUKURA Transcript Split — README and Corpus Map

## Authority note

This corpus is the **V1 historical analytical layer**. It is retained as a comparison and provenance point for later, more structured Shuukura analysis. It must not be treated as current analytical authority once a V2 corpus exists.

## Purpose

This package parses the supplied full Shuukura analysis transcript into independently retrievable analytical artifacts for each numbered light-novel volume and each named side-story/supplement that received substantive analysis. The original transcript is retained under `90_Transcript_Provenance/`.

## Preservation policy

The numbered-volume files preserve the original integrated assistant responses verbatim (apart from this added metadata), including cases where the original analysis discussed supplements inline. Named supplements are also extracted into standalone files so they can be retrieved independently. This intentionally creates some duplication rather than rewriting or deleting context from the original volume analyses.

The export itself carries a warning that turn 0 could not be proven captured; that uncertainty is preserved here. No missing turn has been invented or reconstructed.

## Canonical retrieval route

1. Start with this corpus map.
2. For a numbered volume, use `02_Sequential_Readings/SHUUKURA_V##_DEEP_READING.md`.
3. For a named bonus/side story, use the corresponding file in `03_Supplemental_Readings/`.
4. Use `90_Transcript_Provenance/` only when exact conversational provenance is needed.
