## Operational model obligation

Future model artifacts must contain conditional trigger/stakes/state → response-family rules, inhibitors, exceptions, rivals, falsifiers and evidence routes. Separate disposition from temporary condition; trace appraisal → decision → recipient-conditioned speech/graphic expression. Each projection states confidence, distance from observed contexts and an abstention or multiple-response rule. This descriptive schema is not a model itself.

Freeze true held-out predictions before source exposure. Independent evaluators compare outcomes with diagnostic baselines, decoys or controls where appropriate, preserving opportunity denominators and confounds. Exposed work is RETROSPECTIVE_CONSISTENCY_TEST. Synthetic outputs cannot become canonical evidence. Monographs and global readiness registries have distinct owners/responsibilities.

## Closeout and full-output handoff

Accept complete readings and synchronized registers atomically. Verify page coverage, retrieval, prospective boundaries, state/relationship specificity, ordinary controls, language/form reasoning and bounded name/reference review. Missing required evidence remains a hold.

An authorized run sets actual checkpoint cadence; the architecture's four-volume proposal is not authorization or an arc claim. Freeze full inputs and complete state histories. A checkpoint summary cannot replace extensive earlier arguments.

Follow the [handoff contract](../../governance/source-policies/MANGA_ANIME_ANALYTICAL_HANDOFF_AND_INTEGRATION_CONTRACT.md): transfer complete files, inspect them, and compare base/candidate/current before mutation. Check for lost counterevidence, causal steps, language ambiguity and ordinary-life detail. One owner updates this register; parallel specialists own distinct artifacts against frozen inputs.
