# IDOLY PRIDE V2 PHASE 1 — PASS-A RECONNAISSANCE REPORT

## Result

The corpus can be triaged without relying on prior chat selection. The current analytical surface contains **665 game bundles** representing **3,879 granular source stories**, plus **12 anime episodes**, for **677 Pass-A analytical units**.

The old selected-event corpus is useful but demonstrably incomplete: it contains **53/60 current event bundles**, all of them events, and therefore says nothing directly about the 63 main-story bundles, 33 unit-origin bundles, 20 bonds, 363 card bundles, 99 message bundles, 27 specials/misc bundles, or anime formal evidence.

## Most important methodological finding

V2 should not ask whether a source was historically called “core.” It should ask what source class it belongs to, what stable model it changes, what later evidence pressures it, and where it routes in the mature synthesis.

## Immediate late-corpus correction

The directly inspected July 2026 event `event_2026_007_st-eve-2607-marathon-raid` (`PRIDE貫く頂点への道標`) is absent from the historical selection but merits **CORE** status in the current Pass-A ledger. It places SUNNY PEACE after BIG4 status, explicitly denies that achievement equals a final summit, and frames DoriKyun as a difficult external benchmark through which SUNNY PEACE seeks further growth. It therefore routes to SUNNY PEACE, competitive ecology, idolhood/performance, and manager/guidance analysis.

This does not prove every omitted late event is core. It proves the historical boundary is no longer safe.

## Priority policy now in force

- Tier-A governing narrative is `CORE` by default.
- Mana origin material is `FOUNDATIONAL`.
- Events and bonds begin `IMPORTANT` and must earn promotion/demotion through semantic review.
- Cards/messages begin `TEXTURE`, but this is not a ceiling.
- Specials/misc begin `UNRESOLVED`.
- Historical event priorities are stored as advisory metadata only.

## Next tranche

The next Phase-1 tranche should semantically audit the **main-story and unit-origin layers first**, because they establish the reference model against which event/card/message significance must be judged. After that, all 60 events should be re-ranked independently, with the 53 historical selections treated as hypotheses rather than inherited answers.
