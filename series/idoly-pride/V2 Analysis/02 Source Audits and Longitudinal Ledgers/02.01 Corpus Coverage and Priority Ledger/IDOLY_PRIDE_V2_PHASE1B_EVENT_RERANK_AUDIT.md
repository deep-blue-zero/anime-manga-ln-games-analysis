# IDOLY PRIDE V2 — PHASE 1B EVENT RERANK AUDIT

## 0. Executive finding

The event corpus is not a homogeneous supplement to the main story. Across all **60 raw event bundles**, it divides into four analytically different strata: a compact set capable of revising the frozen Tier-A model; a larger set that materially extends characters, units, labor, and institutions; a support layer whose value is chiefly relational or ordinary-life texture; and a low-delta/crossover layer that should remain indexed without consuming early close-reading bandwidth.

The most important methodological correction is that **dramatic plot scale and analytical value are not equivalent**. Several low-key events become high priority because they expose health intervention, institutional dependence, center authority, persona construction, career longevity, public memory, or the limits of score/rank ontology more cleanly than tournament arcs. Conversely, several historically `CORE`-tagged seasonal events fall to E2 or E3 because the Tier-A reread has already stabilized the claim they once seemed necessary to establish.

The strongest event-level pressure cluster is the linked 2025 IIIX United States arc (`event_2025_005` → `event_2025_007`). It directly enters the Tier-A deferred miho/Yō memory problem, IIIX autonomy, global professional identity, reason-for-continuation, and ranking-system critique. **This is a routing conclusion only. None of those candidate findings is admitted to the governing baseline until the formal event close-read phase freezes them.**

## 1. Corpus and exclusion rules

- Raw event bundles inspected: **60 / 60**.
- Release distribution: **2021: 6; 2022: 12; 2023: 12; 2024: 12; 2025: 11; 2026 through July: 7**.
- Historical duplicate `CORE_` / `IMPORTANT_` copies were excluded from the evidence set.
- The two 2025 `free` bundles were treated as ordinary event evidence, not bonus material.
- Release order was not assumed to equal diegetic order. Chronology is represented by broad dependency tags unless the text supplies a firm anchor.
- Crossover events remain indexed but receive `CROSSOVER_CANON_CAVEAT`; internal IDOLY PRIDE characterization may still be reusable later if independently supported.

## 2. Integrity disclosure

This was **not perfectly blind** with respect to historical prioritization. The raw corpus census, scoring dimensions, high-candidate identification, and provisional tier boundary were established before the historical event table was used for comparison. Historical labels were then exposed. Three unexpectedly large divergences (`event_2022_012`, `event_2024_007`, `event_2025_010`) triggered targeted primary-source rereads. Their scores were revised because the text supported greater value, not because the historical label was treated as authoritative.

The correct integrity label is therefore:

`CONTROLLED_RERANK_WITH_DISCLOSED_HISTORICAL_LABEL_EXPOSURE`

The independent scoring file is retained separately for auditability.

## 3. Routing rubric

Each event receives a heuristic routing score. The score is **not an epistemic truth value**; it only decides reading order and analytical bandwidth.

| Code | Dimension | Range | Meaning |
|---|---|---:|---|
| `S` | State-change magnitude | 0–4 | How much the event changes or newly exposes a durable character/unit state |
| `O` | Tier-A open-question relevance | 0–4 | Direct pressure on `OPEN-01`–`OPEN-20` |
| `C` | Character/relationship coverage | 0–3 | Value for undercovered people, pairs, or unit internals |
| `I` | Institution/labor value | 0–3 | Management, contracts, work, school, health, industry, audience, career structure |
| `R` | Revision/contradiction potential | 0–3 | Capacity to qualify or overturn a frozen Tier-A/V1 claim |
| `J` | Japanese voice/register value | 0–2 | Unique relationship grammar or self-description requiring close Japanese reading |
| `H` | Chronology/dependency value | 0–2 | Importance for placing a state transition or bridging arcs |
| `D` | Redundancy penalty | 0 to −3 | Material already better established by stronger sources |

### Tier thresholds

- **E1 / CORE: 19–21.** Must close-read before specialist syntheses.
- **E2 / IMPORTANT: 13–18.** High-value extension/complication; close-read after E1.
- **E3 / SUPPORT: 8–12.** Targeted relational, voice, labor, or ordinary-life evidence.
- **E4 / LOW-DELTA OR CAVEATED: ≤7 or strong crossover caveat.** Indexed, selectively mined, not early close-read priority.

Final distribution:

- **E1:** 16
- **E2:** 26
- **E3:** 7
- **E4:** 11

## 4. Highest-priority routing conclusions

### 4.1 IIIX/Yō is the strongest unresolved event dependency

`event_2025_005` and `event_2025_007` form a mandatory linked read. Part 1 removes the three members' inherited reasons for continuing IIIX and reaches an explicit dissolution decision; Part 2 forces a re-authorization of continuation while directly challenging miho on whether private remembrance of Yō is enough. This pair is the event corpus' clearest candidate to resolve or radically revise `OPEN-09` and materially extend `OPEN-10`.

### 4.2 Event evidence can sharpen the ethics of risk beyond Stellar

`event_2023_009` is a particularly important control case for Sakura/Makino. Haruko chooses bodily safety over a one-time result and forfeits, giving the project a clean comparison against Stellar's supported-risk model. This does not settle `OPEN-01`/`OPEN-03`; it makes the unresolved conflict more precise.

### 4.3 Metric sovereignty is attacked repeatedly outside the main story

`event_2023_011`, `event_2024_006`, and the IIIX US pair all pressure the idea that score, rank, or victory can own a career. The event corpus therefore appears likely to turn the Tier-A phrase **competition without ontological erasure** into a broader industry critique rather than a BIG4-local conclusion.

### 4.4 Center authority generalizes beyond the BIG4 endpoint

`event_2026_002` is a direct test of `OPEN-15`: all five Tsuki members enter a center contest, Nagisa wins on performance, and the others remain both collaborators and future competitors. If the close read survives adversarial scrutiny, BIG4's “contestable professional office” model will no longer be limited to Kotono/Suzu.

### 4.5 Hoshimi memory is institutional, local, and iterative

`event_2021_004`, `event_2023_006`, `event_2024_010`, and `event_2026_003` form a memory/institution chain: annual ritual, Saegusa/Hoshimi origin history, hometown continuity, and later answer-song reinterpretation. These should be read together before the Mana/Makino specialist synthesis is drafted.

## 8. Chronology policy for event close reading

The rerank deliberately avoids pretending every event can already be assigned an exact slot. Four chronology confidence classes should govern the next pass:

1. **Hard anchor:** the event names an explicit main-story boundary (`BIG4_INTERCALATION_PRE_DORIKYUN_FINAL`, IIIX transfer, etc.).
2. **State anchor:** membership, BIG4 status, affiliation, or career condition proves it occurs after a known transition.
3. **Release-adjacent but diegetically uncertain:** the event clearly reflects a later mature state but exact placement is not yet textually fixed.
4. **Crossover/caveated:** diegetic placement should not be used to rewrite native chronology without corroboration.

Every close-read document must preserve both `release_position` and `diegetic_position`, and must record uncertainty rather than forcing a false total chronology.

## 9. Anti-backfill rule

No event finding in this audit may silently enter the frozen Tier-A baseline. During formal event close reading, each candidate must be classified as `EXTENSION`, `STABILIZATION`, `RELAPSE_RECURSION`, `REVISION`, `CONTRADICTION`, `TEMPORAL_MATURATION`, `TEXTURE`, `FORMAL_DEPENDENCY`, or `CHRONOLOGY_CORRECTION`. Only after a tranche freeze may a successor governing baseline absorb it.
