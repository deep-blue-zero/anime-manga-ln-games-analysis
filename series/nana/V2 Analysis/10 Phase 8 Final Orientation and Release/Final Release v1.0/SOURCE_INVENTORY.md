# NANA v1.0 — Source Inventory

This inventory records the source identities that govern the v1.0 analytical release. **No copyrighted manga EPUB, CBZ, or PDF payload is included in the delivery archive.** The purpose of this file is to preserve provenance, hashes, source-language boundaries, and the distinction between sources directly revalidated during Phase 8 and sources whose identity remains locked by the canonical sequential analyses and frozen evidence ledger.

## 1. Source hierarchy

1. **Original Japanese manga page images, Volumes 1–21** — governing primary literary evidence.
2. **Chapters 81–84 fan-translated scans** — primary narrative continuation for events, visual sequence, chronology, broad relational structure, and thematic analysis, but not for Japanese micro-linguistic claims.
3. **`NANA 7.8` Japanese official fan book** — official paratext, kept subordinate to the manga for literary claims.
4. **External historical context** — used only where explicitly marked in specialist synthesis; it does not replace the manga.

The anime is not part of this manga release and should be analyzed separately as an adaptation.
