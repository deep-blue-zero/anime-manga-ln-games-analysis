# Blue Archive source-gap impact register

## 0. Boundary and use

The [source reconciliation](BLUE_ARCHIVE_SOURCE_RECONCILIATION_20260928.md) and [current map](../CURRENT_STATE_AND_CORPUS_MAP.md) establish **480 / 480** main readings and 26 chapter checkpoints in the pinned Japanese generation `BA_REFRESH_20260928T032248159554Z`. The [source-class crosswalk](../06%20Evidence%20and%20Indexes/BLUE_ARCHIVE_SOURCE_CLASS_CROSSWALK.md) inventories all **4,864** canonical story objects. Group, event, bond, MomoTalk, mini, character-data, special-operation and unclassified material are **available but not yet admitted** to analysis. This register identifies how each evidence debt limits a particular claim. It does not treat unread material as absent or imply that every possible source class is mandatory for a narrow claim.

Status meanings: `AVAILABLE_UNREAD` means a canonical source route exists but has not been inspected for the stated question; `SOURCE_METADATA_UNRESOLVED` means current metadata cannot establish the proposed identity/title/order; `PRIMARY_TEXT_LIMIT` means the admitted text does not show the needed event or record; `ATTRIBUTION_LIMIT` means a source label, perspective or choice boundary narrows the reading; `SOURCE_CLASS_UNADMITTED` means no approved use of that class has occurred. A gap can carry more than one status. Resolve only the claim-specific effect after an exact source-facing reading; a new inventory count alone is not closure.

The [readiness audit §§21–28](../08%20Audits%20and%20Manifests/BLUE_ARCHIVE_CHARACTER_RECONSTRUCTION_BOOTSTRAP_AUDIT.md#21-current-snapshot-inputs-and-review-scope) provides the current evidence distinctions. The [event index](../06%20Evidence%20and%20Indexes/BLUE_ARCHIVE_EVENT_ANALYTICAL_PRIORITY_INDEX.md) schedules event review without ranking quiet material down. The following gap IDs are stable routes for a future admission record, not invented model-rule IDs.

## 2. Decision record and update rule

For each planned supplementary tranche, append a decision keyed by gap IDs: the claim/question, exact story IDs, reason for inclusion **including ordinary literary value**, source and continuity witness, documentary and narrative chronology, full-inspection state, observed support/counterevidence, effect on the claim, and any remaining debt. `AVAILABLE_UNREAD` changes to a reviewed/admitted state only when source-facing reading and review occur. `PRIMARY_TEXT_LIMIT` remains until the missing observation actually appears. A main-only pilot can proceed with explicit ordinary/private exclusions where its bounded claim permits; a broad character portrait cannot treat those exclusions as filled evidence.

Current decisions: **metadata intake only; zero supplemental story admissions**. The [event index](../06%20Evidence%20and%20Indexes/BLUE_ARCHIVE_EVENT_ANALYTICAL_PRIORITY_INDEX.md) identifies review prompts without assigning text-based literary priority. The [source-class crosswalk](../06%20Evidence%20and%20Indexes/BLUE_ARCHIVE_SOURCE_CLASS_CROSSWALK.md) owns complete source routes and chronology handling. New source discoveries or changed claims update the affected gap row and source locator rather than silently removing a debt.
