## 1. Status vocabulary

Source-class cells use:

- `ANALYZED` — admitted into the current analytical corpus;
- `AVAILABLE_NOT_REVIEWED` — the promoted source/derived corpus exposes the class or retrieval route, but this project has not inspected it for the subject in this tranche;
- `ROUTE_NOT_VERIFIED` — the corpus class exists, but a subject-specific usable route has not been confirmed here;
- `NOT_APPLICABLE` — the class is not a sensible direct subject source;
- `NOT_ADMITTED` — deliberately outside the present source boundary.

Domain cells use:

- `H` — repeated or strongly triangulated within the stated current boundary;
- `M` — meaningful but context- or relationship-limited;
- `L` — one or a few narrow observations;
- `GAP` — no responsible current operational claim;
- `SPECIAL` — requires a separate treatment, such as Sensei choice-space modeling.

Readiness uses the project-local specification:

- `UNMODELED`;
- `PARTIAL_MODEL`;
- `OPERATIONAL_CANDIDATE`;
- `BOUNDED_VALIDATED`.

All standalone model artifacts are currently `NONE`. A `PARTIAL_MODEL` row means that canonical checkpoint/ledger analysis already supports at least one conditional mechanism, not that a finished model exists.
