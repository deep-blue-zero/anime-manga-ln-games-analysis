# Collective action and state ledger

## Responsibility

Preserve how individual perceptions and choices relate to collective outcomes, depicted time and group constraints. This is not a results table. No activity phase, institution, group, event or character state is established at INITIAL.

## Schemas

| Register / key | Required fields |
|---|---|
| Action movement `HQ-A-nnnn` | Exact witness/frontier; source-established movement and actors; entering conditions; perception/appraisal; options/constraints; choice/non-action; coordination; shown consequence; omitted links; rival cause; evidence and full reading |
| Temporal relation `HQ-T-nnnn` | Page/panel positions; disclosure order; depicted order/simultaneity/replay hypothesis; phase/time constraint if source-established; supporting/contrary evidence; alternatives; confidence |
| Knowledge `HQ-K-nnnn` | Subject/group member/narrator/reader position; proposition; known/believed/reported/unknown status; acquisition route/time; audience; who lacks it; evidence; prospective/retrospective mode |
| Group/institution `HQ-G-nnnn` | Source-established group; membership/role boundary; rule versus custom versus testimony; resource/access conditions; observed practice/enforcement; exceptions; collective versus individual interest; change evidence |
| Causal dependency `HQ-CD-nnnn` | Outcome/question; proposed contributing action/information/resource; necessary/sufficient/correlated/unknown relation; counterfactual/rival; evidence limits; claim versions and downstream effects |

Store exact state as witness/version + admitted frontier + disclosure + depicted-time constraint + knowledge + role/resources + directed relationship links. Unknowns remain explicit. Scores, techniques, rules and positions enter only if inspected pages establish them; external knowledge cannot populate a missing cell.

## Analytical and update rules

The full reading develops each mechanism and its alternatives. The ledger routes that argument. Parallel panels, commentary and reaction inserts require separate temporal inference, not automatic succession. A successful result does not uniquely identify intention, cause or ability; missing motion cannot be reconstructed as direct observation.

At each accepted volume, append new/changed states and explicit inspected no-change findings. Preserve earlier hypotheses and knowledge states; later explanations create linked revisions. Group-level claims require evidence about scope and diversity rather than one speaker's confident assertion.

Checkpoint review retrieves the central action chains, tests plausible alternative contributions and distinguishes individual/collective knowledge. Consequential timing/identity changes trigger claim, character, visual and specialist dependency review. One active sequential owner mutates this ledger; independent checkpoint review can propose changes with evidence.
