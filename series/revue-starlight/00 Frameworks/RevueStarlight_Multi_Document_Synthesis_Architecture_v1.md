# 『少女☆歌劇 レヴュースタァライト』
## Multi-Document Synthesis Architecture
### Document map, primary-home rules, production order, and delivery standard for the definitive animated-corpus synthesis

## 0. Purpose

This file defines the division, order, scope, and internal coordination of the next comprehensive *Revue Starlight* synthesis.

It is the architectural companion to:

> `RevueStarlight_Full_Series_Analytical_Method_v1.md`

The analytical method determines:

> **how evidence is read and evaluated.**

This architecture determines:

> **where each question is developed, how documents relate, how duplication is prevented, and in what order the corpus should be produced.**

The multi-document format is justified not because the animated corpus is especially long, but because *Revue Starlight* operates through several analytical systems that become distorted when compressed into one essay:

- nine principal Stage Girls with distinct developmental arcs;
- several dyadic relationships that function almost like independent dramatic systems;
- the 99th class as an ensemble ecology;
- the inherited play 『スタァライト』 as an internal intertext;
- the audition and Revue system;
- Position Zero;
- the Giraffe and spectatorship;
- Japanese dialogue and character voice;
- performed vocal states;
- Revue songs and score;
- choreography and weapons;
- visual symbolism and stage machinery;
- the difference between television episodic form and feature-film form;
- and the sequel film's retrospective pressure upon successful television resolutions.

The governing architectural principle is:

> **Separate documents by governing question, not merely by character name or motif.**

A second principle is:

> **Every major subject receives one primary analytical home. Other documents may invoke it briefly, but should cross-reference rather than reproduce the same deep dive.**

A third principle is:

> **Chronology, character, relationship, music, staging, audience, ethics, and theatrical intertext must remain connected without being collapsed into one master metaphor.**

A fourth principle is:

> **The final corpus should preserve the difference between local close reading and retrospective synthesis.**

## 4. Recommended scale

The architecture recommends:

- **14 core analytical documents**, including README and comparative reference;
- **one required chronological evidence ledger**;
- **one optional but strongly recommended Japanese dialogue/lyric/motif index**;
- a corpus manifest with checksums and source inventory.

Recommended combined scale:

- **70,000–105,000 words** for Documents `01–13`;
- **15,000–25,000 words** for the evidence ledger;
- variable length for the Japanese/lyric index.

These are planning ranges, not quotas.

Depth should come from:

- evidence density;
- cross-media comparison;
- contradiction testing;
- and primary-home discipline.

Repeated plot summary is not depth.

# III. Drafting order

The production order should differ from reader order.

1. Freeze the corpus map and source codes.
2. Build `14_EPISODE_MOVEMENT_AND_REVUE_EVIDENCE_LEDGER.md` from the existing close readings while re-verifying load-bearing audiovisual evidence.
3. Draft `01_SERIES_ARCHITECTURE...`.
4. Draft the three major relationship documents:
   - `02` Karen/Hikari;
   - `03` Junna/Nana;
   - `04` Maya/Claudine.
5. Draft `05` and `06` to cover the remaining major relationships, individual character identities, and ensemble ecology.
6. Draft `07` Revue system / audience / Position Zero.
7. Draft `08` *Starlight* intertext / repetition / re-production.
8. Draft `09` music / song / Japanese voice.
9. Draft `10` visual / cinematic grammar.
10. Draft `11` ethics / self-authorship.
11. Draft `12` endings / graduation / next stage.
12. Draft `13` comparative matrices and open questions.
13. Write `00_README...` only after terminology and final theses stabilize.
14. Complete `15_JAPANESE_DIALOGUE_LYRIC_AND_MOTIF_INDEX.md`.
15. Run a cross-document duplication, contradiction, evidence, and locator audit.

Why this order?

> **Evidence first → chronology → relationship centers → ensemble → theatrical system → inherited text → sound/voice → image → ethics → ending → comparative export.**

- Motifs are not treated as one-to-one code.

## Ethics

- Explanation is not justification.
- “Healthy” is not used as a vague reward label.

- Every major topic has one primary home.
- Cross-references replace duplication.

- Comparative document contains no major first-time argument.
