A psychologically accurate character with the wrong information is still an inaccurate reconstruction. Therefore every scenario or longitudinal interpretation should resolve:

> **temporal state + relationship state + knowledge state**

before generating behavior or dialogue.

## 2. Knowledge classes

- **DIRECT_WITNESS** — character directly observed event/statement.
- **DIRECT_DISCLOSURE** — another participant explicitly told them.
- **INFERENCE_STRONG** — well-supported inference from observed evidence.
- **INFERENCE_WEAK** — plausible but not established.
- **BELIEF_INCORRECT_OR_DISTORTED** — sincerely held but source-corrected belief.
- **AUDIENCE_ONLY / AUDIENCE_RICHER** — analytical knowledge not available to participant.
- **UNKNOWN_TRANSMISSION** — source does not establish whether information was later passed on.
- **OPEN** — unresolved.
