## 2. State model

A state record should normally contain:

- **state_id** — stable analytical identifier;
- **character**;
- **valid_from / valid_through** — source or analytical boundary;
- **status** — historical / current-within-cutoff / superseded-as-default;
- **self-concept**;
- **goals**;
- **active fears / vulnerabilities**;
- **emotional baseline**;
- **agency profile**;
- **coping / defenses**;
- **relationship conditions**;
- **knowledge constraints** — pointer to epistemic ledger rather than duplication when possible;
- **speech/register changes**;
- **transition trigger**;
- **key evidence**;
- **confidence**;
- **next-state pointer**.

Historical states are append-only. A later state may become the default reconstruction state without invalidating an earlier state for historically bounded scenarios.
