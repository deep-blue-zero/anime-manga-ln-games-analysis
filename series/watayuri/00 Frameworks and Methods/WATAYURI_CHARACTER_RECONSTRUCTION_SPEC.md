# Character reconstruction specification

**Responsibility:** define the gate and contents for future operational character models, subordinate to `characters/RECONSTRUCTION_CAPABILITY_SPEC.md`. This is a method, not a character model, capability record, or grade. No one is assessed or simulation-ready at bootstrap.

## Promotion sequence

The [cast and readiness ledger](../03%20Longitudinal%20Ledgers/WATAYURI_CAST_AND_RECONSTRUCTION_READINESS.md) records first evidence and confidence without inventing a cast list. Create an independent **evidence ledger** only when recurring observations for one character require cumulative retrieval beyond the ensemble ledgers. Create a **reconstruction model** only when observed decisions support testable time-indexed behavioral rules with explicit failure and alternative conditions, beyond a descriptive summary. Create a **monograph** only when the evidence supports sustained integration of development, psychology, relationships, speech, manga form, contradictions, and thematic function. These are distinct, independently gated artifacts; no directory is pre-created.

## Model contract once evidence exists

Specify the exact continuity and VNN endpoint, source witnesses and locators, evidence holes, stable dispositions versus state/role/relationship-dependent responses, self-conception and values where demonstrable, attachment/jealousy regulation, conflict thresholds, avoidance/confrontation, information-conditioned choices, boundaries and repair, written speech repertoire, humor/play, negative constraints, and unresolved ambiguity. Separate what the character publicly says, privately reports, demonstrably does, and what the analyst infers. A later disclosure changes mature explanation without changing the frozen earlier knowledge state. Identify counterexamples, confidence and likely model failure modes. Test predictions against withheld later evidence only when the prospective record actually predates it; do not retrofit a forecast.

## Cross-series portability is a second gate

Literary understanding alone does not establish portable simulation. A bounded scenario specifies a **source-state timestamp**, what the character knows, whether the Liebe or other role script operates, relationship history, and which contextual assumptions have been transplanted. Compare predictions with and without the institutional script; identify behavior supported only for a particular relationship. Mark unfamiliar-personality interactions as extrapolation with a plausible range, negative constraints, and an abstention condition when evidence is insufficient. Written manga speech can constrain phrasing and register, not acoustic performance.

Before a model is used as a cross-series behavioral authority, evaluate its coverage, contradictions, alternatives, holdouts and scope using the global reconstruction capability specification and the project's readiness record. An owner or authorized curation process controls global capability records and character discovery. This bootstrap creates none, and assigns no A–E grade.
