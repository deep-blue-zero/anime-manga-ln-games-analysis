## Prospective-freeze rule

Each numbered main volume begins from the frozen state after the previous numbered volume. Before reading the next volume, record important open questions and predictions. Later evidence may revise the current model but must not silently rewrite the earlier freeze.

At the current boundary, Sections 8-10 of `TOMOZAKI_V11_DEEP_READING.md` control any future numbered-volume resumption. Before a newly admitted volume is opened, copy that bounded state into a new pre-prose freeze and stage it. Preserve all earlier volume documents as historical analytical states; do not use later knowledge to retrofit V11 conclusions, V08.5 adjudications, or earlier predictions.

## Minimum responsibilities

Each deep reading should cover, as evidence warrants:

- exact audited source witness;
- scene/event structure and focalization;
- character-state changes and contradictions;
- relationship and peer-network changes;
- social learning, tactics, habit, and internalization;
- competence/confidence/status/self-concept/agency changes;
- coaching, refusal, consent, and self-authorship questions;
- self-presentation/authenticity evidence;
- game/rank/optimization metaphors and their limits;
- ordinary-life evidence;
- wording/register-sensitive Japanese evidence;
- DIRECT evidence versus inference, hypothesis, prediction, and value judgment;
- rival readings and counterevidence;
- revision status of prior claims;
- bounded next-volume questions and predictions.

A deep reading is not a chapter transcript and should not duplicate the source. Select evidence because it changes an analytical state.
