# 20. Volume Artifact and Evidence Index

## 1. Function

This document is the routing layer between the final specialist corpus and the seventeen immutable sequential readings.

It is **not** another volume-by-volume synopsis.

Its function is to answer a narrower set of questions quickly:

- Which artifact owns the local first-pass reading of a scene or claim?
- What was that artifact's local thesis?
- Is its evidence system native-v2 or migrated?
- Which evidence identifiers should a later synthesis document use?
- Does the claim already have a primary-source locator?
- Which later retrospective corrections should be consulted before turning the local reading into a full-series claim?
- What exact Japanese EPUB object underlies the artifact?

The traceability chain is:

> synthesis claim  
> → specialist document  
> → Document 19 claim ID / thematic ledger  
> → this artifact index  
> → canonical volume or bonus deep reading  
> → evidence ID / backfill ID  
> → Japanese source locator  
> → original EPUB passage or illustration.

## 2. Corpus-level evidence status

The completed sequential analytical corpus contains approximately **209,298 whitespace-delimited words** across seventeen canonical artifacts.

Evidence infrastructure is intentionally asymmetric:

- **V1–V7** preserve migrated historical first-pass readings. Phase 0 added **80 exact-anchor synthesis backfills** without rewriting those interpretations.
- **V8–V15** were produced natively under V2 and contain stable evidence and locator ledgers.
- **Animal Land** and **Spring Days** are native-v2 bonus analyses with complete locators and explicit publication/story-position separation.

The native-v2 and bonus artifacts contain **1,273 stable evidence entries**. The three controlled early-volume backfill layers now contain **120 exact V1–V7 routes**: 80 from Phase 0, 20 from Phase 3, and 20 from Phase 4. The current package therefore provides **1,393 controlled evidence routes**.

The original 47 broader migrated scene-level claims have been reduced to **17 still awaiting claim-triggered backfill**. These remaining items are predominantly negative claims, broad causal syntheses, or unresolved-mechanism assertions for which one quotation would be misleading. Their existence is deliberate: the project reopens an early EPUB only when a later specialist document actually needs that claim as load-bearing evidence.
