# AoButa Object, Place, and Memory Ledger — Final

## 1. Governing proposition

AoButa repeatedly externalizes fragile memory and personhood through material objects and revisitable places.

The object or place does not ordinarily contain a whole person.

It provides:

- evidence;
- retrieval cue;
- continuing relation;
- social legibility;
- a setting in which old and new meanings can coexist.

## 4. Material-memory rules

### Rule 1 — objects do not equal persons

A donor heart does not make Shoko Toko.

A photograph does not contain all of Kaede.

A song does not make a lookalike Miori.

### Rule 2 — objects can preserve access

The trophy, diary, notebook, pass, and song provide routes when memory or social recognition fails.

### Rule 3 — meaning can change without erasing prior meaning

- panda;
- curry bun;
- zoo;
- smartphone;
- song.

The object remains.

The relation changes.

### Rule 4 — places become mature when they can hold more than one history

The final series repeatedly revisits locations without demanding that the old event recur.

That is the spatial equivalent of:

> `思い出に変える`.
