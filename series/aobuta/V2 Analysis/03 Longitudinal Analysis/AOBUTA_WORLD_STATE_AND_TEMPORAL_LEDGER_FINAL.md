# AoButa World-State and Temporal Ledger — Final

## 1. Purpose

This ledger prevents the completed synthesis from using **timeline**, **future**, **dream**, **possible world**, and **rewrite** as interchangeable words.

The series presents several temporally abnormal structures with different evidence profiles.

## 4. Why `R1` should not be called a simple branch

The strongest resistant evidence is simultaneous Kaede/Hanakaede embodiment.

Earlier volumes tied the two autobiographical continuities to one body and one mutually exclusive history. R1 gives each a body and current life.

A simple statement—

> Sakuta traveled to an already existing timeline

—does not explain this without additional assumptions.

The safer formulation is:

> **R1 is a rewritten or synthetic possibility state capable of actualizing outcomes that were previously mutually exclusive.**

## 5. Memory hierarchy

The series uses at least six memory forms:

1. ordinary autobiographical memory;
2. memory of unrealized future experience;
3. counterpart-world memory;
4. relational memory restored by recognition;
5. material archive memory;
6. ethical memory retained after the phenomenon ceases.

The finale privileges the sixth.

Sakuta's solution does not require preserving every possible world as current.

It requires preserving what those experiences made him able to do.

## 6. Final world-state judgment

The architecture should not call `RF` the **objectively correct** timeline merely because it is final.

The stronger claim is normative:

> **RF is the history the series chooses because its major goods can continue through ordinary self-authorship rather than nonconsensual reality optimization.**

That choice remains ethically expensive because R1 preferences—especially Kaede's and Rio's—were real.
