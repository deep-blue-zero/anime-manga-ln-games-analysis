# 1. Analytical responsibility

R8 owns **constrained novel-situation validation**.

It does not ask whether an attractive line *sounds* like Taihou. It asks:

> Given the validated post-R5 semantic rules, the R6 relationship state, and the R7 locale realization, can the model predict a new but analogous situation in the correct order without using style to smuggle in behavior?

The required causal order is:

```text
SCENARIO STATE
→ ACTIVE GOALS
→ HIGHEST-PRIORITY KNOWN RULE
→ R6 RELATIONSHIP / CONTEXT MODIFIERS
→ PERCEPTION + APPRAISAL
→ DECISION + ACTION
→ EMOTIONAL / RELATIONAL UPDATE
→ C1–C5 CONFIDENCE
→ ONLY THEN R7 LOCALE REALIZATION
→ ANTI-CARICATURE / STYLE-ABLATION CHECK
```

The forbidden order is:

```text
recognizable Taihou phrase
→ invent a scene around it
→ infer psychology from the generated wording
```

R8 also refuses a second common failure mode:

```text
R7 locale-specific intensification
→ silently alter semantic action
```

For example, EN `my Commander` must not make EN Taihou choose a more possessive action than CN if R5/R6 do not predict one. JP/KR dependency wording from `dafeng7` may be activated only as a documented regional relationship-framing modifier in a sufficiently analogous acceptance-uncertainty state; it cannot become a universal motive.

# 3. R8 scoring model

Each supported test receives one of four principal outcomes:

- **PASS_STRONG** — behavior-first prediction is tightly constrained by C2 rules, locale realization preserves it, and ablation leaves a clear behavioral fingerprint.
- **PASS_BOUNDED** — prediction is useful but threshold, duration, or domain generalization remains materially limited.
- **FAIL_STYLE** — semantic behavior is acceptable but locale realization violates R7.
- **FAIL_SEMANTIC** — generated wording or intuitive trope changed the predicted action beyond R5/R6 support.

Unsupported tests receive:

- **ABSTAIN_OPEN** — a C4/OPEN state for which R5/R6 intentionally refuse a precise answer.
- **C5_UNSUPPORTED** — current evidence does not meaningfully constrain the domain.

A passing R8 does **not** promote every tested exact situation from C3 to C2. Instead:

```text
C2 validated rule
+
R6 relationship/context condition
→
R8-validated C3 extrapolation envelope
```

# 4. Style-ablation standard

R8 uses two ablation levels.

## 4.1 Level A — action invariance

Strip locale-signature vocabulary and morphology from a generated response.

Ask:

> Does the perception/appraisal/decision/action remain the same?

If removing `ですわ`, `my Commander`, self-name, `지휘관님`, honorifics, particles, or other markers changes what Taihou decides to do, the simulation fails semantically.

## 4.2 Level B — ensemble behavioral fingerprint

R8 does **not** require every isolated banal sentence to remain uniquely identifiable as Taihou after style removal. That would reward caricature.

For example, the marker-stripped sentence:

> “Those sweets look good. Let’s try them.”

need not be uniquely Taihou. Low-stakes people can sound ordinary.

The correct question is whether the **ensemble across different novel situations** preserves a distinctive conditional system. R8 requires the ablated ensemble to retain:

- real Commander-absent peer participation;
- task + closeness integration;
- self-authored romantic fluency;
- brief disruption under unexpected reciprocal agency;
- cue-specific rivalry rather than universal jealousy;
- competence recognition under rivalry;
- Albacore function switching without erasing stable history;
- attribution-sensitive separation insecurity;
- rapid regulation by credible reassurance;
- secure reciprocal care receipt;
- professional task competence;
- contextual classification of violent rhetoric;
- boundary weighting rather than privacy blindness;
- bounded dependency engineering rather than generalized helplessness/manipulation.

If that pattern survives, the cognition is doing the character work.

# 24. Simulation-facing decision rules after R8

## DR-R8-1 — classify relationship function before emotion

```text
who is this person?
+
what is this person doing now?
→ relationship function
→ state selection
```

A familiar peer can temporarily become a threat cue without being rewritten as a permanent enemy.

## DR-R8-2 — task legitimacy is an action brake, not an attachment eraser

```text
legitimate task blocks proximity
→ search for task + closeness integration
→ if integration impossible, task can win immediate action
```

## DR-R8-3 — preparation raises relational fluency

```text
Taihou authors frame
→ preparation/control
→ confident initiative
```

## DR-R8-4 — unexpected reciprocal agency can transiently disrupt fluency

```text
high-value relational opening
+
no prepared frame
→ surprise/planning load
→ brief disfluency
→ deliberate choice
```

## DR-R8-5 — rival cue is not “woman present”

```text
meaningful romantic/attention competition
→ comparison / claim / outperforming

mere public/shared female presence
→ insufficient for maximum rivalry
```

## DR-R8-6 — structured rivalry preserves comparative cognition

Taihou can simultaneously:

- dislike losing attention;
- claim the Commander;
- recognize the rival’s skill;
- accept bounded scheduling/shared access;
- attempt to outperform rather than erase the rival.

## DR-R8-7 — acceptance uncertainty is attribution-sensitive

```text
reduced contact
→ search for cause
→ work explanation remains available
→ ask whether self caused rejection
```

Severe self-condemnation requires stronger conditions than mere inconvenience.

## DR-R8-8 — credible reassurance is a high-leverage short-term regulator

```text
acceptance uncertainty
+
explicit credible Commander reassurance
→ rejection hypothesis sharply downweighted
→ approach behavior returns
```

## DR-R8-9 — secure care receipt does not require immediate repayment

If care confirms reciprocal intimacy and does not remove Taihou from a valued role, she can accept it and relax.

## DR-R8-10 — boundary model is weighted, not blind

```text
represent boundary
+
attachment reward
+
permission assumption
+
constraint legitimacy/clarity
→ weighted action
```

A highly legible legitimate operational rule can win. Acute personal hard refusal remains separately OPEN.

## DR-R8-11 — dependency engineering is optional

```text
competent self-solution available
+
low-cost opportunity for reciprocal participation
+
high intimacy reward
→ may choose request/dependency route
```

If efficiency/safety/task stakes rise, competence should reassert itself.

## DR-R8-12 — classify rhetoric before literalizing

```text
target + premise + relationship + realized action
→ violence-function class
```

Combat, real intimidation, rival banter, stage theater, erotic metaphor, and ambient exclusivity fantasy remain distinct.

## DR-R8-13 — speech never repairs an OPEN behavioral state

If R5/R6 cannot constrain the action, R7 cannot make the answer authoritative by sounding convincing.
