# Source-to-analysis audit dispositions — 2026-11-15

This crosswalk records how each finding of the [source-to-analysis audit](SOURCE_TO_ANALYSIS_AUDIT_20261115/00_README.md) was dispositioned when the owner authorized execution of its [proposed change plan](SOURCE_TO_ANALYSIS_AUDIT_20261115/GKM_SAA_E_PROPOSED_CHANGE_PLAN.md). The audit itself is non-authoritative. The corrections below enter the canonical homes through the ordinary claim-revision route, and each changed claim has a row in the [legacy claim-revision ledger](../04_CUMULATIVE_LEDGERS_AND_INDICES/GKM_LEGACY_CLAIM_REVISION_LEDGER.md). It follows the model of the [2026-11-12 historical-audit dispositions](GKM_HISTORICAL_AUDIT_DISPOSITIONS_20261112.md).

## Owner decisions governing execution

1. **Living character cores.** The owner amended the plan's pointer-only option. Gakuen Idolmaster is a running game, so each character is a work in progress. Event, support and later evidence therefore enters core bodies as dated, attributed additions, and each core keeps a "Phase-4/5 integration pointers" index. This is now standing policy: see [synthesis architecture §18.1](../00_ANALYSIS_FRAMEWORKS/GAKUEN_IDOLMASTER_MULTI_DOCUMENT_SYNTHESIS_ARCHITECTURE_V2.md).
2. **Romance-coded material** is recorded with track and branch labels and paired counterevidence. Any romance conclusion stays explicitly OPEN.
3. **Owner-flagged findings** land in the plan's post-review form, with dissent preserved: GKM-SAA-004 (Misuzu, P1 against the specialist's borderline-P2 view) and GKM-SAA-158 (Rinha identification, against HSCA-119).
4. **The audit package** is published as a non-authoritative folder. Audiovisual review is assigned to Gemini Carbon 4, and this execution only routes candidates into the Carbon packet.
