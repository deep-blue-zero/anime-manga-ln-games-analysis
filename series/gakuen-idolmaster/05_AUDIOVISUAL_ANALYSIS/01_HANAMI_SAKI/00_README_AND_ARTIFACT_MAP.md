# README AND ARTIFACT MAP

## Purpose

This package closes the Phase-3 Hanami Saki audiovisual baseline. It integrates the user-supplied songs, official MVs, game 3DMVs, and whole dialogue commus with the pre-existing source-grounded character-core reading.

## Reader order

1. `GKM_SAKI_COMPLETE_AUDIOVISUAL_BASELINE.md` — integrated argument and final baseline thesis.
2. `GKM_SAKI_MUSIC_MV_AND_PERFORMANCE_CLOSE_READING.md` — work-by-work music/MV analysis.
3. `GKM_SAKI_DIALOGUE_VOICE_ACTING_CLOSE_READING.md` — six requested dialogue scenes and voice-state model.
4. `GKM_CORE_01_HANAMI_SAKI_AV_REVISION_ADDENDUM.md` — revisions to import into the later definitive character monograph.
5. `GKM_SAKI_AV_EVIDENCE_AND_METRICS_MATRIX.md` — technical/evidentiary appendix.
6. `GKM_PHASE3_SAKI_AUDIOVISUAL_COMPLETION_REPORT.md` — exit criteria and preserved uncertainties.

## Evidence and provenance

- `GKM_PHASE3_SAKI_AUDIOVISUAL_SOURCE_MANIFEST.json` records canonical file identities, byte sizes, SHA-256 values, codecs, resolutions, frame rates, audio streams, and raw-script hashes.
- `music_features.*` and `dialogue_*prosody*` are derived analytical aids. They do not replace direct interpretation of the rendered sources.
- Updated ledger snapshots preserve the cumulative project state after this pass.

## Source boundary

The package contains **no source audio/video, no frame extracts, and no raw ADV scripts**. The primary audiovisual material remains in the user's Google Drive/Library and is identified by hash in the source manifest.

One uploaded 2160p60 Re;IRIS file had a malformed MP4 audio sample table and was excluded. The valid 1080p60 duplicate was used as the canonical `雨上がりのアイリス` source.

## Compact thesis

> Hanami Saki's defining audiovisual identity is a conversion process: exposure becomes propulsion, bodily effort becomes spectacle, private contradiction becomes direct address, and breakage becomes accumulated forward motion. `Fighting My Way` presents fragmented invincible self-production; `Wildest Flower` reconstructs it as relational indomitability.
