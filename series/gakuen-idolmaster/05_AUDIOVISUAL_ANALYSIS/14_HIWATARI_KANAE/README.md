# Hiwatari Kanae — audiovisual analysis

Kanae can speak with impeccable courtesy while refusing an assignment, asking for help or inviting a crowd to run with her. The change that links these scenes is whom she is prepared to address on her own behalf. Her first original gives that change a musical form. This supplement adds Kanae as the fourteenth playable character with a local audiovisual home. The historical Phase 3 release covered thirteen.

## What would change this reading

- A native B or D narrative-end banner in a continuous run, or an observed performance grade and wrapper caption paired with the conditions that selected it, would narrow the interface question. Replicated runs through overlapping conditions would test their precedence. A capture with an unlocked *メタモルフォーゼ* tile selected and played would answer the separate archive-playback question.
- Complete native lesson and second-supply transitions with their final words intact would extend the two partial Run B matches. A matching asset is already available for each.
- A second distinct original, later communication or comparable performance of the same material could test whether the observed relationship between formal address and freer stage movement persists. A claim about vocal development would also require comparable repertoire, arrangement and recording conditions. An isolated vocal would answer a different question from the sound of the released mix.
- New material identifying the speaker behind the blackout in China’s separate P3 scene would affect that attribution. The episode is outside the evidence used here for Kanae’s performed address.
