## Unit convention

Use the narrowest stable narrative unit that preserves causal and dramatic coherence:

- main-story patch/chapter/act or quest chain;
- companion story;
- event story;
- archive/favor sequence when it functions as a narrative unit;
- another explicitly justified unit.

Each filename should use `WUWA_<SCOPE>_<ARTIFACT_ROLE>.md`, with stable technical IDs recorded in front matter and the body even when the human-readable title is used in the filename.
