Each of these twelve directories now has a source-bounded literary/behavior reconstruction packet with a deep dive, evidence and falsification matrix, compiled model, machine-audio analysis, and AV retrieval plan. The packets are `draft_noncurrent`: publication does not constitute owner adoption, complete human four-dub listening, or observed runtime-scene analysis. Their existing visual-design profiles remain separately scoped; the drafts do not replace those visual claims or change global character-registry authority.

All listed character directories contain `CHARACTER_VISUAL_DESIGN_PROFILE.md`, its machine-readable JSON projection, and `CHARACTER_VISUAL_REFERENCE_MANIFEST.json`. Each profile is bounded to three directly inspected official-client UI rasters for the default playable presentation: a head icon, formation art, and activity portrait. The manifests preserve asset paths, package/container provenance, hashes, form/skin/state labels, uncertainty, and reverse provenance. Raw PNGs remain restricted outside Git; the profiles do not claim a runtime model, rear view, animation study, complete skin/form survey, or scene-level audiovisual analysis.

For an owner-adopted packet, start with its `CURRENT_STATE` router and `ANALYSIS_PACKET_README`; for a noncurrent draft, start with its linked packet README above. The [earlier five-character import record](../08%20Audits%20and%20Manifests/WUWA_PRE_AV_CHARACTER_PACKET_IMPORT.md) records byte preservation and the pending AV boundary for that earlier set.

The [Chisa import record](../08%20Audits%20and%20Manifests/WUWA_CHISA_PRE_AV_REBUILD_IMPORT.md) records the later twelve-document rebuild and its publication provenance. The [authority adoption record](../08%20Audits%20and%20Manifests/WUWA_CHARACTER_PACKET_AUTHORITY_ADOPTION.md) makes that earlier five-character packet set current within its stated text/audio scopes.

The [Sigrika import record](../08%20Audits%20and%20Manifests/WUWA_SIGRIKA_V0_2_IMPORT.md) records the later audio-refined packet, its owner adoption, and the boundary that keeps the complete object-level evidence supplement and media outside Git.
