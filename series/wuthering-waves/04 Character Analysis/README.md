Visual-profile-only directories:

- `Augusta/`, `Brant/`, `Cantarella/`, `Changli/`, `Iuno/`, `Jinhsi/`, `Luuk Herssen/`, `Phoebe/`, `Qiuyuan/`, `Shorekeeper/`, `Yinlin/`, and `Zani/` — individualized V0.2 visual-design profiles with machine-readable claims and official-client provenance manifests; no full literary/behavior packet is claimed.

Every current character directory contains `CHARACTER_VISUAL_DESIGN_PROFILE.md`, its machine-readable JSON projection, and `CHARACTER_VISUAL_REFERENCE_MANIFEST.json`. Each profile is bounded to three directly inspected official-client UI rasters for the default playable presentation: a head icon, formation art, and activity portrait. The manifests preserve asset paths, package/container provenance, hashes, form/skin/state labels, uncertainty, and reverse provenance. Raw PNGs remain restricted outside Git; the profiles do not claim a runtime model, rear view, animation study, complete skin/form survey, or scene-level audiovisual analysis.

Start with each character's `CURRENT_STATE` router and `ANALYSIS_PACKET_README`. The [import record](../08%20Audits%20and%20Manifests/WUWA_PRE_AV_CHARACTER_PACKET_IMPORT.md) records byte preservation and the pending AV boundary.

The [Chisa import record](../08%20Audits%20and%20Manifests/WUWA_CHISA_PRE_AV_REBUILD_IMPORT.md) records the later twelve-document rebuild and its publication provenance. The [authority adoption record](../08%20Audits%20and%20Manifests/WUWA_CHARACTER_PACKET_AUTHORITY_ADOPTION.md) makes that earlier five-character packet set current within its stated text/audio scopes.

The [Sigrika import record](../08%20Audits%20and%20Manifests/WUWA_SIGRIKA_V0_2_IMPORT.md) records the later audio-refined packet, its owner adoption, and the boundary that keeps the complete object-level evidence supplement and media outside Git.

The [visual-profile publication record](../08%20Audits%20and%20Manifests/WUWA_CHARACTER_VISUAL_PROFILE_V0_2_IMPORT.md) records the 18-character, 54-artifact analytical layer and its raw-media exclusion.

A folder is not evidence that every contract artifact exists. Missing artifacts are created only by a substantive analysis that warrants them.
