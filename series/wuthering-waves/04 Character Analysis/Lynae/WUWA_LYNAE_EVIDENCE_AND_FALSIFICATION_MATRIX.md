# Lynae evidence and falsification matrix

## Use rule

This matrix separates source facts from increasingly interpretive claims.

Classifications:

- **source fact** — directly stated or mechanically demonstrated in the accepted source;
- **stable observation** — repeated behavioral/textual pattern with little causal interpretation;
- **strong inference** — a causal or structural explanation supported by multiple independent surfaces;
- **candidate thesis** — useful higher-order synthesis that should remain especially vulnerable to counterevidence.

Later evidence should not be added merely as another confirming example. It should be coded by whether it:

- preserves an invariant;
- strengthens confidence;
- narrows scope;
- supplies a counterexample;
- changes the causal explanation;
- reveals recipient or state dependence;
- or requires retirement.

AV targets refer to the later audiovisual phase required by `WUWA_CHARACTER_RECONSTRUCTION_PROTOCOL.md` V0.2. They are **tests**, not claims that the scene has already been visually reviewed.

- recorded original-Lynae mission lines rejected by identity adjudication;
- unresolved generic line at row `10832` talk 28;
- unresolved generic line at row `12103` talk 0;

- English-only metaphors treated as Chinese-source personality facts;
