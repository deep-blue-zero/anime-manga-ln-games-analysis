# 2. Source hierarchy

For V2 analytical claims, use the following hierarchy:

1. **Original Japanese numbered EPUB text** — governing primary evidence.
2. **Authenticated Japanese side-story / scenario / guidebook prose in the supplied corpus** — primary or paratextual evidence depending on item.
3. **Publication-local conclusions in V2 per-volume deep readings** — analytical artifacts, not evidence substitutes.
4. **Longitudinal V2 ledgers** — retrieval/audit infrastructure.
5. **V1 synthesis and V1 transcript** — hypothesis/provenance layer only.
6. **Translations, anime adaptations, subtitles, fandom summaries, external commentary** — secondary evidence only when explicitly requested or analytically necessary.

A later source cannot silently overwrite an earlier volume's publication-local epistemic state. Later evidence belongs in retrospective-correction sections.
