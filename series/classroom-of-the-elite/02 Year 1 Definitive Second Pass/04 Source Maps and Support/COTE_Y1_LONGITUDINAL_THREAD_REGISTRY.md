### Definition refinements

- `AYANOKOJI_FREEDOM` now routes resistance to ownership and external control; positive end-setting routes additionally through `AYANOKOJI_SELF_AUTHORSHIP`.
- `AYANOKOJI_AUTHORSHIP` remains the broad control/structuring thread; use `RECIPROCAL_AUTHORSHIP` when the question is specifically whether another person's authorship survives the intervention.
- `JITSURYOKU` now explicitly includes possession, development, expression, legibility, coordination, and recording.
- `TRUTH_PROOF_RECORD` retains the record-sovereignty line; `INSTITUTIONAL_LEGIBILITY` covers the distinct problem of what a file/metric can know.
- `RELATIONSHIP_RECIPROCITY` remains the relational-information/refusal thread; `HIDDEN_CURRICULUM` is used when intimacy itself becomes a developmental environment.

# Year 1 Longitudinal Thread Registry
## Controlled retrieval vocabulary through `Y1V10`

This registry defines stable thread IDs used in YAML metadata, evidence ledgers, checkpoint ledgers, and later year-level or full-series synthesis. It is deliberately compact. New IDs should be added only when an existing thread cannot represent a recurring governing question without distortion.

# 1. Usage rules

1. Apply a thread only when the evidence materially advances, complicates, or contradicts it.
2. A scene may carry multiple threads when it performs genuinely different analytical functions.
3. Do not use thread IDs as conclusions. They are retrieval routes.
4. Later evidence must not silently change the meaning of an existing ID; revise the definition explicitly if needed.
5. Volume-local artifacts retain their spoiler boundary even when later ledgers use the same thread.
