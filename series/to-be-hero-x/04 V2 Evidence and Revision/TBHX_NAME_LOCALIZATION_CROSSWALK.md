# TBHX Name and Localization Crosswalk

## 1. Responsibility and current authority

This is the current identity-resolution layer for the *To Be Hero X* V2 corpus. It reconciles:

- Mandarin source-script names and spoken address forms;
- stable V2 analytical forms;
- official English hero/person/organization labels;
- official Japanese renderings;
- historical project forms;
- and identity-state distinctions that cannot safely be represented by one interchangeable name.

It is **authoritative for current name resolution but not archivally frozen**. Phase 2 Tranche 03A completes the first systematic E01–E24 audit. Phase 7 must still perform a claim-to-source and locator audit; Phase 9 alone promotes the file to immutable `canonical` release status. The metadata therefore uses `active_provisional`, not `canonical`, while `do_not_use_as_current_authority` remains false.

This file is not a license to alternate surfaces freely. A name can identify a private person, a hero role, a brand, a family address, a professional title, a group identity, a hostile epithet, an institutional category, or a later historical reframing. The corpus must preserve those semantic responsibilities.

## 3. Authority hierarchy

1. `EPISODE_PRIMARY` — Mandarin episode audio/hardsub and visible source text. Governs what characters say, source-script wording, address, titles, and episode-local identity knowledge.
2. `OFFICIAL_CN` — verified official Chinese series/account materials. Governs published Chinese naming and hero branding when available.
3. `OFFICIAL_EN` — official English character site. Governs the official English localized surface; it does not override Mandarin dialogue semantics.
4. `OFFICIAL_JP` — official Japanese character site and aligned subtitle witness. Governs the Japanese-edition surface and can support phonetic equivalence, but cannot reconstruct unspoken Mandarin distinctions.
5. `SECONDARY` — discovery or corroboration only. Never overrides episode-primary or official material.
6. `V1_LEGACY` — historical project terminology, preserved for provenance rather than current authority.
