# Purpose

This catalog reconciles the validated 24-episode extraction manifest with the project Library ingestion state. It distinguishes **corpus expectation**, **user-reported upload state**, and **direct binary verification** so that Library search limitations are not mistaken for missing source material.

# Verification rule

`DIRECTLY_VERIFIED_ATTACHED` means the ZIP binary was addressable in the current conversation and inspected. `USER_REPORTED_LIBRARY_UPLOADED_NOT_ENUMERABLE` means the user reports the bundle is present in the project Library, but File Library search did not surface the ZIP by exact filename; no claim about its binary integrity is made until it becomes addressable. `STAGED_ATTACHED_UNINSPECTED` means the user has directly attached the bundle for a future episode, but the project has intentionally not opened or verified its binary yet in order to preserve episode-order workflow.
