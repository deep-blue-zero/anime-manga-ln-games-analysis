# Chiramune sequential readings

This directory is the canonical home for source-bounded volume deep readings.

## Naming

Use:

- `CHIRAMUNE_V01_DEEP_READING.md`
- `CHIRAMUNE_V02_DEEP_READING.md`
- continuing by numbered main volume.

Create a supplemental reading only when an acquired supplement has actually been read and has enough analytical responsibility to warrant its own artifact. Do not create placeholder files for unread volumes.

## Prospective rule

Each numbered main volume is read from the frozen analytical state produced by the prior numbered volume. Record expectations/open questions before opening the new volume for analysis, audit them afterward, then freeze the new reading before advancing.

Later volumes can revise the current model. They cannot rewrite the historical record of what the earlier source boundary supported.

## Supplemental sequencing

- **Volume 03 illustration/SS booklet:** main Volume 03 freezes first; classify and read the booklet afterward.
- **Volume 05 special edition:** use regular Volume 05 for mainline prospective reading; integrate distinct SS/supplemental material only after V05 freezes.
- **Volume 06.5:** classify publication and diegetic placement before integration; preserve the main numbered prospective chain.
- **Volume 08 special edition:** it is the current complete V08 narrative witness. Analyze the main novel portion and freeze V08 before using the rough-illustration supplement as supplemental evidence when technically distinguishable.
- **Days of Endless Summer:** treat as a later side-story collection whose individual stories require provenance/placement before integration.
- **Volume 09.5:** treat as supplemental/current-publication material rather than silently redefining the numbered V09 prospective boundary.

## Minimum deep-reading responsibilities

A numbered deep reading should cover, as evidence warrants:

- event/scene structure and focalization;
- character-state changes and contradictions;
- relationship developments;
- social-group dynamics and informal status;
- ordinary-life evidence;
- self-presentation, disclosure, aspiration, and identity claims;
- recurring motifs/form/language where meaningful;
- direct facts versus inference;
- rival readings and counterevidence;
- prospective expectations for the next unread numbered volume.

The deep reading is an analytical artifact, not a chapter-by-chapter plot transcript.
