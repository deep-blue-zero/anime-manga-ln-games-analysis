# Chiramune revision ledger

## Responsibility

This is the canonical rolling home for explicit transitions between prospective source boundaries. It prevents later evidence from silently overwriting a claim that was reasonable at an earlier horizon.

Each transition preserves the earlier formulation, its boundary, the later testing evidence, the transition state, and the current formulation. Exact support remains in the linked deep reading, freeze, or thematic ledger; this file routes rather than duplicates every passage.

Allowed transition states are:

- `PRESERVE`
- `STRENGTHEN`
- `REVISE`
- `DOWNGRADE`
- `REJECT`
- `OPEN`
