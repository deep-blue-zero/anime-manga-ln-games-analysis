# Chiramune longitudinal-ledger router

No longitudinal ledger is instantiated at bootstrap. This file records when one should be created and what responsibilities are likely to recur.

A ledger earns a canonical file when the same analytical question must be updated across multiple volume freezes and retrieving it only from individual deep readings becomes unreliable.

Candidate responsibilities include:

- character state, self-concept, and developmental change;
- relationship, intimacy, disclosure, reciprocity, and rivalry;
- peer-network topology, social status, inclusion/exclusion, and informal authority;
- authenticity, self-presentation, masking, performance, and self-fashioning;
- aspiration, future adulthood, work/study goals, and imagined ordinary life;
- recurring imagery, metaphors, stylistic/formal patterns, and distinctive language.

These are **candidate ledger responsibilities, not predetermined theses**. Combine responsibilities when the evidence is sparse; split them only when independent revision/retrieval becomes useful.

Every longitudinal entry should preserve the volume boundary that established it. Later recontextualization may revise the current interpretation without erasing the earlier prospective state.
