# Chiramune character-analysis router

V01–V04 currently justify four active-provisional cumulative monographs:

- `Saku Chitose/CHIRAMUNE_SAKU_CHARACTER_MONOGRAPH.md`;
- `Yuzuki Nanase/CHIRAMUNE_YUZUKI_CHARACTER_MONOGRAPH.md`;
- `Asuka Nishino/CHIRAMUNE_ASUKA_CHARACTER_MONOGRAPH.md`.
- `Haru Aomi/CHIRAMUNE_HARU_CHARACTER_MONOGRAPH.md`.

Saku's cumulative monograph preserves the complete V01 baseline and appends explicit V02, V03-main, V03-booklet, and V04 revisions. Yuzuki's monograph is promoted at V02 because direct focalization, retrospective self-account, ordinary-life evidence, relationship contrast, crisis behavior, and counterevidence together cross the independent-model threshold; the V03 booklet and V04 each add bounded revisions. Asuka's monograph is promoted at V03 because direct focalization, childhood formation, ordinary-life demystification, family conflict, researched vocation, directional love, and significant ethical counterevidence together create an independently useful model; V04 adds only a bounded current-category correction. Haru's monograph is promoted at V04 because prologue/epilogue focalization, athletic formation, leadership failure and revision, ordinary life, direct love, two independently important relationships, embodied risk, and substantial counterevidence create a durable analytical responsibility.

Do not create another monograph or character subdirectory merely because a cast member appears in the source.

Create `04 Character Analysis/<Character>/` when source-grounded longitudinal evidence is sufficient to support a durable analytical responsibility.

Potential artifact responsibilities, instantiated only when warranted:

- `<CHARACTER>_CURRENT_STATE.md` — first-read router when a character has multiple active artifacts or a changing source boundary;
- `<CHARACTER>_CHARACTER_MONOGRAPH.md` — canonical integrated character interpretation;
- `<CHARACTER>_RELATIONSHIP_AND_STATE_LEDGER.md` — when developmental/relationship states are too complex for monograph-only retrieval;
- `<CHARACTER>_ORDINARY_LIFE_AND_PREFERENCES_PROFILE.md` — when mundane behavioral evidence materially improves reconstruction;
- `<CHARACTER>_SPEECH_AND_REGISTER_PROFILE.md` — when diction, terms of address, social register, rhetoric, or focalized narration warrant independent treatment;
- claim/counterevidence, fidelity, or reconstructive-model artifacts — only for a character-modeling project dense enough to justify them.

A monograph should distinguish stable tendencies from state/recipient effects, integrate contradictory evidence, and identify abstention boundaries. It is not a trait list.

Update a current monograph in place through explicit boundary-labeled revision. Preserve an earlier prospective character state in its volume freeze and revision ledger rather than maintaining two simultaneously current cumulative copies.

Global enrollment in `characters/registry.jsonl` and `CHARACTER_ANALYSIS_INDEX.md` is a separate reviewed discovery decision. Mere source appearance or creation of a local character folder does not require global enrollment.
