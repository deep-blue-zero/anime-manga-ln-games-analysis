# Chiramune character-analysis router

No character monograph or character subdirectory is canonical at bootstrap. Do not create one merely because a cast member appears in the source.

Create `04 Character Analysis/<Character>/` when source-grounded longitudinal evidence is sufficient to support a durable analytical responsibility.

Potential artifact responsibilities, instantiated only when warranted:

- `<CHARACTER>_CURRENT_STATE.md` — first-read router when a character has multiple active artifacts or a changing source boundary;
- `<CHARACTER>_CHARACTER_MONOGRAPH.md` — canonical integrated character interpretation;
- `<CHARACTER>_RELATIONSHIP_AND_STATE_LEDGER.md` — when developmental/relationship states are too complex for monograph-only retrieval;
- `<CHARACTER>_ORDINARY_LIFE_AND_PREFERENCES_PROFILE.md` — when mundane behavioral evidence materially improves reconstruction;
- `<CHARACTER>_SPEECH_AND_REGISTER_PROFILE.md` — when diction, terms of address, social register, rhetoric, or focalized narration warrant independent treatment;
- claim/counterevidence, fidelity, or reconstructive-model artifacts — only for a character-modeling project dense enough to justify them.

A monograph should distinguish stable tendencies from state/recipient effects, integrate contradictory evidence, and identify abstention boundaries. It is not a trait list.

Global enrollment in `characters/registry.jsonl` and `CHARACTER_ANALYSIS_INDEX.md` is a separate reviewed discovery decision. Mere source appearance or creation of a local character folder does not require global enrollment.
