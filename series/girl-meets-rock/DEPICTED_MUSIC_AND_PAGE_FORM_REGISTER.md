# Depicted music and page form register

## Responsibility

Record how manga depicts expression, performance and audience response, without treating depiction as heard execution. The bibliographic premise justifies this capture responsibility; actual music/form specialist need remains unassessed. No page, lyric, instrument or performance has been inspected.

| Record / key | Required fields |
|---|---|
| Depicted action `GMR-DA-nnnn` | Exact witness/page/panel; visible body/instrument/object as source-established; action endpoints; omitted motion; uncertainty; no inferred continuous technique; full argument |
| Lettering/lyric/notation `GMR-L-nnnn` | Exact page/region; source-language form and quote status; speech/thought/lyric/quotation/notation/sound-effect class; speaker/performer attribution as supported; minimal eligible excerpt/gloss; ruby/base; semantic and channel limits |
| Performance assertion `GMR-PA-nnnn` | Speaker/narrator; exact claim about sound/skill; knowledge/reliability; source boundary; distinction from direct hearing; corroborating/contrary page evidence |
| Audience response `GMR-AR-nnnn` | Exact reaction/order; observer/subject; visible or reported response; possible causes/rivals; who knows what; no automatic acoustic-quality conclusion |
| Page form/rhythm `GMR-V-nnnn` | Exact page/spread/facing basis; panels/gutters/silence/reactions/rendering; graphic pacing or implied rhythm; feature/effect/alternative; counterexample; not measured tempo |
| Japanese voice `GMR-J-nnnn` | Speaker/thinker/narrator/recipient; exact route; verified short words; appraisal/objective/speech act/register; lyric versus personal assertion; graphic lettering; gloss alternatives and controls |
| Reference/debt `GMR-RD-nnnn` | Exact on-page reference or missing evidence; independently admitted external object if any; relation/non-equivalence; required inspection; affected claims; owner/resolution |

Quote status is EXACT_VERIFIED/WORKING_TRANSCRIPTION/PARAPHRASE. OCR and remembered lyrics are not exact verification. Sound effects can describe manner/state rather than audible events. A lyric quotation is not automatically autobiography.

## Channel and update rules

Every claim records what the page shows, what a participant asserts, and what the analyst infers. No record can certify heard pitch, timbre, tempo, tuning, vocal delivery, synchronization or instrumental execution from absent audio. Any narrower source statement must be labeled as that statement.

Read and retain full page-based arguments, including ordinary rehearsal/practical contexts if present, not just a reference list. Verify spread/page-turn structure and inspect silent pages. Recurrence and implied rhythm need exact evidence, variation and alternatives.

Append records only after actual accepted inspection. Source/mapping changes reopen retrieval. At checkpoint test whether an imagined or familiar recording has contaminated an interpretation; downgrade unsupported channel claims and preserve valid page analysis. One owner maintains this register.
