# The Witch from Mercury — Reading transaction and reconciliation protocol

## Scope

This contract implements independent source reading and atomic state advancement for the [method](../framework/GWFM_ANALYTICAL_METHOD.md). It establishes roles and records, not completed participation. No narrative reading occurs in this bootstrap.

## Standing reading configuration

| Role | Assignment and evidence access |
| --- | --- |
| Principal analyst and analytical integrator | Inspects the complete authorized unit through required lanes; develops causal/literary reading, reconciles contributions and alone updates shared ledgers and current state |
| Independent character/language specialist | Inspects assigned scenes directly, retaining Japanese wording, cognition, ordinary-life evidence and directed relationship differences; forms observations before receiving principal conclusions |
| Independent critical reviewer | Normally a third context, distinct from principal and specialist; directly checks diagnostic evidence, frontier/attribution, counterexamples, missing character evidence and proposed acceptance |
| AV specialist/reviewer when required | Verifies actual audio/continuous perception, source clocks and sampled resolution; answers neutral formal/performance questions before seeing the interpretation |
| Repository author | Validates/publishes the reconciled series change; may be principal, but analytical acceptance and repository validation remain separate |

P00 and full TV episodes use the default configuration. **No reduced unit class is preauthorized** by this architecture. An unusually bounded future supplemental unit may use the topology policy's reduced configuration only after admission and a recorded per-unit justification; genuine independent source-aware contribution and review remain mandatory.

A separate context must have its own stated assignment and source access without inheriting unnecessary interpretive state. Role-play inside one model context is not independence. Provider diversity is optional; evidence access is not. The current bootstrap assigns no real workers and certifies no source-inspection capabilities.

All participants share the authorized frontier, not future episodes. Do not hand a prior-horizon specialist the full later reading, a spoiler-bearing source map or the principal's conclusions under the label “context.” Record actual exposure and any contamination.

## Durable unit receipt

Create `GWFM_<unit>_TRANSACTION.md` only for a real transaction. It preserves:

1. owner-authorized run reference, start/terminal boundary, mode, unit/witness and entering accepted state;
2. required channels, capabilities actually tested, coverage intervals and missing layers;
3. each participant's identity/role, independent context, observed configuration or UNKNOWN, assignment and actual exposure;
4. independently inspected source intervals, material observations and locator IDs;
5. interpretations, alternatives, counterexamples, corrections and unresolved evidence obligations;
6. integrator disposition of each material contribution: adopted, qualified, rejected with evidence, or left open;
7. reading/ledger/claim/source-map deltas and preservation of meaningful specialist evidence;
8. semantic review outcome, unresolved limits, acceptance status and actual high-water change.

A list of agent names or “review passed” is insufficient. Public receipts preserve substantive sanitized findings without raw transcripts or private source paths. Publication workflow results remain in Git/PR status, not duplicated as durable current-map facts.

## AV reconciliation

Reconciliation profile: per-unit queues for load-bearing movement/agency, combat geography, microperformance, music–image timing and editing claims. Use [the corpus protocol](../../../governance/source-policies/MANGA_ANIME_AUDIOVISUAL_RECONCILIATION_PROTOCOL.md), with the method's targeted/full escalation rules.

1. Principal supplies a neutral observation packet with intervals, channel, question, clock and required/optional status. Withhold the claim/adjudication packet.
2. Reviewer verifies combined AV perception and actual effective sampling, calibrates the object to bundle anchors, and records observation coverage. Full episodes normally use beginning/middle/end anchors; exact precision follows the question.
3. Reviewer freezes independent observations, then reads the claim packet and records every PRESERVE / STRENGTHEN / REVISE / DOWNGRADE / REJECT / OPEN result and new finding.
4. Integrator tests source mapping and lane permissions, considers inaccessible-channel observations seriously, and routes material reliability concerns to targeted verification. No provider has automatic interpretive authority.
5. Return a disputed item once with a specific question; if still load-bearing and unresolved, use one independent verification route when available. Continued disagreement remains OPEN. Do not iterate toward manufactured consensus.
6. Apply accepted findings to current claims and cumulative homes. Frozen readings receive errata/revisions, never silent edits.

ANCHORED observations require calibrated, rechecked source intervals and adequate resolution. REPORTED observations retain their limits. An observation dispute and an interpretive disagreement are distinct. Missing or unknown sampling cannot support a sub-sampling timing claim.

A missing required route blocks its acceptance responsibility. Optional AV enhancement can remain pending, explicitly described; it cannot be counted as inspected or accepted.

## Atomic closeout and recovery

Before advancing a unit:

- inspect all required narrative material and preserve genuine prospective captures before resolving them;
- complete the independent specialist/reviewer contributions and reconcile substantive differences;
- ensure the readable synopsis precedes extended interpretation and remains unit-bounded;
- run the named-subject/reference check: ambiguous pronouns, conflated aliases, unnamed institutions and unsupported speaker assignments must be repaired or disclosed;
- route locators and required character/relationship/world/form/claim deltas to current canonical homes;
- record source coverage, frontier, residual debt and the next operation allowed by the existing run;
- review the full changed set, then validate and publish through the author checklist.

Interrupted work retains the last **accepted** high-water mark. Inventory partial findings, inspected intervals, unfinished reviewers and uncommitted deltas; recover exact files and run authorization before continuing. Do not restart accepted episodes merely to regain context. Do not call the whole unit complete if only its prose or bundle lane is finished.

## Synthesis transfers and publication

At an accepted tranche, prepare a frozen evidence snapshot and targeted handoff under the [handoff contract](../../../governance/source-policies/MANGA_ANIME_ANALYTICAL_HANDOFF_AND_INTEGRATION_CONTRACT.md). Include complete target artifacts, evidence/claim scope, unit/frontier, relevant ledgers, counterreadings, required versus optional work, current debts and acceptance conditions. A summary alone does not replace the corpus.

The author may modify only this series root and its descriptor. Housekeeping owns generated global routing; character discovery and capability evaluators own their separate outputs. Run staged-index author preflight, approved-identity checks and exact-path diff review, push without force, open/update the series PR and require a successful exact-head Repository integration audit before publishing another tranche. The CI agent or owner integrates main under repository policy.
