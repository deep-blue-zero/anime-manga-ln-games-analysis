# The Witch from Mercury — Character-state ledger

Preserve the evidence needed to understand people across changing situations, rather than reducing them to roles or a list of traits. This is also the named home for later monograph qualification decisions and task-specific model-readiness notes.

## Shared record discipline

The principal/integrator is the single mutable owner. Add records only from an accepted or explicitly provisional source transaction inside its authorized horizon. Every record binds a stable ID, unit and witness, source frontier, evidence IDs, evidence class, confidence, current claim references and review disposition. Use exact source names with stable subject keys once verified; preserve uncertain attribution rather than guessing.

Append event/revision history. Update a clearly identified current-state projection only from that history; preserve earlier boundaries and frozen checkpoints. Never overwrite an old belief with later knowledge. One locator ID may support several dimensions without duplicating raw source material.

At bootstrap there are **zero narrative records**. Header definitions below are contracts, not synthetic examples or findings. This file is current authority for its schema only; no narrative claim is eligible as evidence.

## Character-state record

| Field | Required content |
| --- | --- |
| character_key / names / attribution | Verified identity, aliases known at this horizon, unresolved identity links |
| event_time / disclosure_unit | When something happens versus when it becomes available to the reader |
| knowledge / belief / uncertainty | What this person demonstrably knows, believes or cannot yet know |
| situation / interlocutor / audience | Ordinary or crisis context, public/private setting, actual choice opportunity |
| goals / values / fears / self-conception | Directly stated versus inferred; current conflict or vulnerability |
| options / decision / outcome | Perceived alternatives, chosen conduct, consequence and willingness/capacity distinction |
| disposition / state / change_cause | Recurrence versus temporary condition; development versus late disclosure |
| speech / performance_refs | Japanese register and separately verified delivery/body evidence |
| ordinary_life / preferences | Activity, habit or preference, with alternatives and accommodation context |
| capability / limits | Demonstrated competence, unavailable resources, cost and inhibitors |
| relationships / counterexamples | Directed relationship records, exceptions and rival explanations |
| evidence / claim / review | Locator IDs, propositions, uncertainty and transaction disposition |

Preserve household, school/work, leisure and humorous evidence when available; a series of crisis responses cannot automatically model everyday life. Do not diagnose from one scene or assign hidden motives because an eventual outcome is remembered.

## Monograph qualification decisions

No character is assessed at bootstrap. Create the first actual decision here when differentiated evidence justifies assessment, and review the candidate set at checkpoint/specialist-readiness boundaries.

A decision records: subject identity; admitted and temporal boundary; source-grounded qualification rationale; evidence variation and counterexamples; largest gaps; outcome; next review trigger; portrait path once the document exists; and acceptance receipt. Outcomes: QUALIFIED_PENDING, COMPLETE_AT_BOUNDARY, DEFERRED_EVIDENCE, REASSESS_AFTER_REVISION.

Eligibility is evidence-based across the entire cast, not a predefined lead roster. A QUALIFIED_PENDING decision is an outstanding production obligation. COMPLETE_AT_BOUNDARY requires separate recorded self-containment and source-fidelity results under the architecture. Do not create placeholder portraits or link imagined paths as completed artifacts.

## Reconstruction readiness notes

For an actually proposed use, record subject@boundary, scenario/domain, supporting evidence, ordinary-life coverage, missing channels/contexts, known limits, actual model/validation paths and next test. These notes confer no global capability tier. An unassessed character has no readiness verdict.
